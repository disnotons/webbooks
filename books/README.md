# books

발행용 웹북 데이터가 들어가는 폴더입니다.

권장 계층:

```text
books/
├─ buddhism/
├─ christianity/
├─ jung/
├─ hawkins/
├─ bailey/
└─ other/
```

각 책은 고유한 영문 소문자·하이픈 폴더를 사용하고, 그 안에 `book.yaml`과 발행용 Markdown을 둡니다.

예:

```text
books/buddhism/madhyama-agama/
├─ book.yaml
├─ 0001_선법경.md
└─ 0002_주도수경.md
```

원본 프로젝트의 Markdown은 여기에서 직접 수정하지 않습니다. 발행용 복사본만 저장합니다.
