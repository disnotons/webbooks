# 『잡아함경 쉬운 완전읽기』 제28권
## 해 뜨기 전 첫빛은 정견이다 — 팔정도·욕망과 대상의 구분·노병사·선지식·세속과 출세간의 바른 길

> **범위:** 『잡아함경』 제28권, 제748경~제796경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』 卷第二十八  
> **수록 경수:** **49경**  
> **읽기 방식:** 제28권은 거의 전부 **팔정도(八聖道)**를 여러 각도에서 반복·확장한다. 제748~767경은 **정견이 왜 첫머리인지, 무명과 밝은 앎이 어떻게 그릇된 길·바른 길을 연쇄적으로 낳는지, 욕망과 감각 대상은 어떻게 구분되는지, 노·병·사와 해탈의 길, 학인과 무학, 팔정도의 수행 방향**을 보여 준다. 제768~783경은 **선지식·바른 사유라는 안팎의 조건과 팔정도의 관계, 이 길을 ‘큰 수레’에 비유하는 장면, 이 언덕과 저 언덕·역류·사문의 의미**를 반복한다. 제784~789경은 특히 중요하게 **세속적 바른 길과 성스러운 출세간의 바른 길**을 구분한다. 마지막 제790~796경은 **악취·선처·열반, 십선·오역, 흐름을 거슬러 가는 길, 사문의 법·뜻·과**로 팔정도를 마무리한다.

---

# 한 문장 핵심

『잡아함경』 제28권은 이렇게 정리할 수 있습니다.

# **괴로움의 끝으로 가는 첫빛은 정견이며, 정견은 나머지 바른 생각·말·행동·생계·정진·마음챙김·삼매를 차례로 일으킨다. 감각 대상 자체가 욕망인 것이 아니라 그 대상에 붙는 탐착이 욕망이고, 전쟁·화재·홍수보다 더 근본적으로 누구도 대신 늙고 병들고 죽어 줄 수 없다는 사실 앞에서 팔정도가 길이 된다. 이 길은 재가자와 출가자 모두에게 열려 있고, 좋은 벗과 바른 사유라는 안팎의 조건으로 자라며, 선한 삶으로 향하는 세속적 팔정도에서 사성제를 직접 관찰해 괴로움을 끝내는 출세간의 팔정도로 깊어진다.**

제28권의 핵심 흐름은 다음과 같습니다.

# **무명**
→ **그릇된 견해**
→ **그릇된 생각·말·행동·생계·정진·마음챙김·삼매**

반대로,

# **밝은 앎**
→ **참괴**
→ **정견**
→ **정사유·정어·정업·정명·정정진·정념·정정**

그리고,

# **정견**
은
# **해 뜨기 전 첫빛**

과 같습니다.

마지막에는,

# **세속적 바른 길**
→ **선처와 건전한 삶**

# **성스러운 출세간 바른 길**
→ **사성제의 직접 관찰**
→ **괴로움의 끝**

으로 정밀해집니다.

# 제1경군 — 제748~767경
## 팔정도의 첫빛 — 정견·무명과 밝은 앎·욕망·노병사·학인과 무학

---

# 제748경 — 해 뜨기 전 첫빛처럼 정견이 먼저다

부처님은 비유합니다.

[비유]

# **해가 뜨기 전에 먼저 밝은 빛이 나타납니다.**

그와 같이,

# **괴로움을 완전히 끝내기 전의 선행 징후**
는
# **정견(正見)**

입니다.

정견이 일어나면,

# **정사유**
# **정어**
# **정업**
# **정명**
# **정정진**
# **정념**
# **정정**

이 일어납니다.

그리고 바른 삼매가 자리 잡으면,
성스러운 제자의 마음은,

# **탐욕**
# **성냄**
# **어리석음**

에서 해탈하고,

> **“생은 다했고, 범행은 섰으며, 할 일을 마쳤고, 다시 뒤의 존재를 받지 않는다.”**

고 직접 압니다.

---

## [주의] 팔정도는 여덟 과목을 아무 순서 없이 병렬로 연습하는가

제748경은,

# **정견이 방향을 잡는 선행 요소**

라고 말합니다.

그러나 이것을,

# **정견이 완전히 끝난 뒤에야 다른 일곱 가지를 시작한다**

는 기계적 순서로 만들지는 않습니다.

다른 경에서는 팔정도의 요소들이 서로 돕고 함께 자랍니다.

핵심은,

# **무엇이 바른 방향인지 보지 못하면**
# **말·행동·정진·마음챙김·삼매도 엉뚱한 방향으로 갈 수 있다**

는 것입니다.

---

해로운 행동을 부끄러워하고 꺼릴 수 있어야,
잘못된 방향을 수정할 수 있습니다.

[주의]

참괴는,

# **“나는 나쁜 사람이다.”**

라는 자기혐오가 아닙니다.

# **해로운 것을 해롭다고 알아 멈출 수 있는 윤리적 감각**

입니다.

---

# 제750경 — 무명이란 단순히 ‘정보가 부족함’이 아니다

제750경은 무명을 아주 구체적으로 정의합니다.

무명은,

# **선과 불선**
# **죄 있는 것과 죄 없는 것**
# **낮은 법과 높은 법**
# **오염된 것과 청정한 것**
# **분별할 것과 그렇지 않은 것**
# **연기하는 것과 그렇지 않은 것**

을 사실대로 알지 못하는 것입니다.

그 때문에,

# **사견**
에서
# **사정**

까지 그릇된 길이 일어납니다.

반대로 밝은 앎은
이들을 사실대로 알아,

# **정견**
에서
# **정정**

까지 일으킵니다.

---

## [주의] 무명 = 공부를 못함?

아닙니다.

초기불교에서 무명은,
일반 지식 부족보다,

# **괴로움과 선악·조건 관계를 사실대로 보지 못하는 근본적인 착오**

입니다.

---

# 제751경 — 재가자와 출가자 모두 같은 방향을 본다

부처님은 말합니다.

# **재가자든 출가자든**
# **그릇된 일을 일으키면 칭찬하지 않고**
# **바른 일을 일으키면 칭찬한다.**

그릇된 일은,

# **사견에서 사정까지**

이고,

바른 일은,

# **정견에서 정정까지**

입니다.

---

## [주의] 팔정도는 출가자 전용인가

제751경은 그렇지 않습니다.

# **재가자와 출가자 모두에게 바른 길과 그릇된 길의 기준이 적용됩니다.**

수행 환경과 세부 계율은 다를 수 있지만,
정견·정어·정업 같은 방향은 공통됩니다.

---

# 제752경 — 대상 자체가 욕망이 아니다

까마 비구가 묻습니다.

> **“욕망이란 무엇입니까?”**

부처님은 먼저 다섯 감각적 즐거움의 대상을 듭니다.

### 눈에 보이는 좋아하는 색
### 귀에 들리는 좋아하는 소리
### 코의 냄새
### 혀의 맛
### 몸의 촉감

입니다.

그런데 곧 중요한 말을 덧붙입니다.

# **“그러나 그것들이 곧 욕망인 것은 아니다.”**

진짜 문제는,

# **그 대상에 대한 탐착**

입니다.

게송은 더 분명합니다.

# **세상의 다양한 색 자체가 욕망이 아니라**
# **그것을 향한 탐욕의 생각이 사람의 욕망이다.**

세상의 대상은 그대로 있어도,

# **수행자는 마음의 욕망을 끊습니다.**

---

## 제752경은 감각수호를 이해하는 핵심 경이다

제572경의,

# **눈도 색도 결박이 아니고**
# **그 사이의 욕탐이 결박**

이라는 가르침과 정확히 연결됩니다.

따라서 초기불교 수행을,

# **아름다운 것을 없애거나**
# **음악·맛·촉감을 악이라고 선언하는 것**

으로 만들면 안 됩니다.

문제는,

# **마음이 그 대상을 ‘내 만족을 위해 반드시 붙잡아야 하는 것’으로 만드는 탐착**

입니다.

---

## 욕망을 끊는 길

까마 비구가 묻습니다.

> **“이 애욕을 끊는 길이 있습니까?”**

부처님의 답은,

# **팔정도**

입니다.

---

# 제753경 — ‘감로’에 이르는 길도 팔정도다

아리숫타 비구가 묻습니다.

> **“감로(甘露)란 무엇입니까?”**

부처님은 `감로`라는 표현을
누가 다한 상태와 연결해 설명합니다.

그리고,

# **감로의 법에 이르는 길**
로
# **팔정도**

를 제시합니다.

[주의]

`감로`를 문자 그대로 마시는 불사의 물질로 읽지 않습니다.

여기서는,

# **죽음과 생사의 결박을 넘어서는 해탈의 상징적 표현**

입니다.

---

# 제754~757경 — 바른 삼매는 나머지 일곱 길 요소 위에 선다

사리불이 묻습니다.

> **“성스러운 바른 삼매의 근본과 갖춤은 무엇입니까?”**

부처님은,

# **정견**
# **정사유**
# **정어**
# **정업**
# **정명**
# **정정진**
# **정념**

이라는 **일곱 길 요소**가
바른 삼매의,

# **기초**
# **근본**
# **갖춤**

이라고 합니다.

이 일곱 위에서,

# **마음이 하나가 되는 것**

을 성스러운 바른 삼매라고 합니다.

현존 한역은 제755~757경을
같은 내용을 다른 질문 형식으로 반복한다고 압축합니다.

---

## [주의] 정정 = 그냥 집중력이 강한 상태

아닙니다.

제754경에서 정정은,

# **정견·윤리·정진·마음챙김이라는 앞선 일곱 요소 위에 서는 삼매**

입니다.

따라서 범죄나 탐욕을 위해 극도로 집중하는 것을
초기불교의 `정정`이라고 할 수 없습니다.

---

# 제758경 — 부모와 자식도 대신 늙고 병들고 죽어 줄 수 없다

제758경은 강렬한 대비를 줍니다.

사람들은,

### 전쟁
### 큰 화재
### 홍수

때 부모와 자식이 헤어지는 것을
‘부모자식도 구해 줄 수 없는 두려움’이라고 말합니다.

그러나 부처님은,
이 경우에는 나중에 다시 만날 수도 있다고 합니다.

더 근본적인 세 가지는,

# **늙음**
# **질병**
# **죽음**

입니다.

---

## 누구도 대신 늙어 줄 수 없다

자식이 늙을 때
어머니가,

> **“네 대신 내가 늙겠다.”**

고 할 수 없습니다.

어머니가 병들 때
자식이,

> **“내가 대신 아프겠다.”**

고 할 수 없습니다.

죽음도 마찬가지입니다.

이 세 가지가,

# **진정으로 서로 대신할 수 없는 두려움**

입니다.

---

## 그렇다면 사랑은 무의미한가

아닙니다.

가족은 서로 돌보고 치료하고 위로할 수 있습니다.

하지만,

# **노·병·사라는 경험 자체를 완전히 대신 살아 줄 수는 없습니다.**

이 사실을 인정하는 것이
자비를 없애는 것이 아니라,
오히려 현실적인 자비의 출발점이 될 수 있습니다.

---

## 이 두려움을 넘어서는 길

다시,

# **팔정도**

입니다.

[주의]

팔정도가,

# **몸이 늙지 않고 병들지 않고 생물학적으로 죽지 않게 하는 기술**

이라는 뜻이 아닙니다.

# **노·병·사를 ‘내 것·나’로 붙잡아 생기는 생사의 괴로움을 끝내는 길**

이라는 수행 문맥입니다.

---

# 제759경 — 세 느낌도 무상하고 조건 지어졌다

세 느낌,

# **즐거운 느낌**
# **괴로운 느낌**
# **즐겁지도 괴롭지도 않은 느낌**

은,

# **무상하고**
# **조건 지어져 있으며**
# **마음이 인연해 생기는 법**

이라고 합니다.

이 세 느낌에 대한 집착과 생사의 결박을 끊는 길도,

# **팔정도**

입니다.

[주의]

느낌 자체를 물리적으로 완전히 없애는 자기파괴 수행으로 읽지 않습니다.

제17권의 핵심처럼,
느낌은 일어나지만 **두 번째 화살과 갈애를 더하지 않는 방향**이 중요합니다.

---

# 제760경 — 노·병·사가 있기에 부처님의 가르침이 필요하다

부처님은,

# **늙음**
# **질병**
# **죽음**

을,

# **좋아할 수 없고**
# **사랑할 수 없고**
# **바라게 되지 않는 세 법**

이라고 합니다.

그리고,

# **세상에 노·병·사가 없다면**
# **여래가 세상에 나타나 가르칠 필요도 없었을 것**

이라고 합니다.

---

## 초기불교의 출발점은 ‘인생 비관’이 아니다

제760경은,

# **노·병·사라는 실제 문제**

가 있기 때문에
해결의 길을 찾는다고 말합니다.

따라서,

# **“인생은 전부 고통이다.”**

라는 막연한 비관론보다,

# **피할 수 없는 노·병·사와 집착의 괴로움을 어떻게 끝낼 것인가**

가 훨씬 정확합니다.

---

# 제761경 — 학인과 무학 모두 팔정도를 갖춘다

부처님은 두 종류를 말합니다.

# **학(學)**

아직 배워 가는 성스러운 수행자는,

# **학인의 정견에서 정정까지**

를 갖춥니다.

# **무학(無學)**

더 배워야 할 것이 없는 아라한은,

# **무학의 정견에서 정정까지**

를 갖춥니다.

현존 경문은 같은 구조를
`정사`·`대사`에도 적용한다고 압축합니다.

---

## [주의] 아라한은 팔정도를 버리는가

제761경은,

# 정견의 두 층위

## 1. 세속적 정견

제784경과 같은,

# **보시·선악업·과보·부모·이 세상과 다른 세상·아라한**

등을 인정하는 정견입니다.

이 정견은,

# **선한 방향과 선처**

로 향하게 합니다.

---

## 2. 성스러운 출세간 정견

성스러운 제자가,

# **괴로움을 괴로움으로**
# **그 원인을 원인으로**
# **소멸을 소멸로**
# **길을 길로**

사유하고,
법을 선택·분별·탐구하고
지혜로 관찰하는 것입니다.

즉,

# **사성제를 직접 관찰하는 지혜**

가 출세간 정견의 중심입니다.

---

# 나머지 일곱 요소도 두 층위가 있다

## 정사유
세속적으로는,

# **출리·무진·불해의 생각**

출세간적으로는,

# **사성제 관찰과 결합한 무루의 마음 방향**

입니다.

---

## 정어·정업·정명

세속적으로는,

# **악한 말·행동·생계를 떠나는 윤리**

입니다.

출세간적으로는,

# **사성제의 무루 관찰과 결합하여**
# **그릇된 말·행동·생계를 단단히 떠나는 성스러운 계**

입니다.

---

## 정정진·정념·정정

세속적으로도 선한 수행이고,
출세간에서는,

# **사성제에 대한 무루의 사유와 결합**

하여 괴로움의 끝으로 향합니다.

---

## [주의] 세속적 팔정도는 ‘가짜’ 팔정도인가

아닙니다.

제785경은 세속적 정견을,

# **선처로 향하는 바른 견해**

라고 분명히 부릅니다.

즉,

# **윤리적 선행과 바른 삶의 토대**

입니다.

다만 괴로움을 완전히 끝내는 데는,

# **사성제를 직접 아는 출세간의 지혜**

로 깊어져야 합니다.

---

## 제785경의 핵심

팔정도는,

# **착하게 사는 길**
에서 끝나지 않고,

# **괴로움의 구조를 직접 보고 취착을 끝내는 길**

로 깊어집니다.

---

# 제786~788경 — 견해가 행동과 결과의 방향을 만든다

제786경은 간단히,

# **그릇된 방향으로 마음이 향하면 법에 어긋나고**
# **바른 방향으로 향하면 법을 좋아하고 어긋나지 않는다**

고 합니다.

제787경은 더 구체적으로,

# **사견이 있는 사람의 몸·말·생각·바람·의도·행동이 그 견해를 따라가고**
# **좋지 않은 결과로 기울 수 있다**

고 합니다.

정견은 반대입니다.

---

# 제788경 — 쓴 씨앗과 단 씨앗

[비유]

# **쓴 씨앗**

을 땅에 심고 물을 주면,
땅·물·불·바람의 영양을 받아도
결과는 씁니다.

반대로,

# **사탕수수·벼·밀·포도 같은 단 씨앗**

은 같은 조건을 받아
단맛을 냅니다.

부처님은,

# **견해를 씨앗**

에 비유합니다.

사견은,

# **사사유에서 사정까지**

를 일으키고,

정견은,

# **정사유에서 정정까지**

를 일으킵니다.

---

## [주의] 한 번 잘못 생각하면 반드시 불행해진다는 운명론?

아닙니다.

제770경은 이미,

# **그릇된 견해는 끊을 수 있고**
# **정견은 닦을 수 있다**

고 했습니다.

씨앗 비유는,

# **반복되는 기본 방향이 말과 행동에 큰 영향을 준다**

는 뜻이지,
한 생각으로 미래가 고정된다는 뜻이 아닙니다.

---

# 제789경 — 정견의 두 층위를 다시 확인한다

생문 바라문이,

> **“정견이란 무엇입니까?”**

라고 묻습니다.

# **세속적 정견**
과
# **성스러운 출세간 정견**

을 나눕니다.

그리고 현존 한역은,

# **정사유·정어·정업·정명·정정진·정념·정정**

도 같은 방식으로 각각 한 경씩 설명한다고 압축합니다.

[주의]

이 압축문을 임의로 긴 원문처럼 복원하지 않습니다.

제785경의 전체 정의가 그 구조를 이해하는 기준입니다.

# 제793경 — 정법은 흐름을 거슬러 가는 길

# **逆流道 — 흐름을 거슬러 가는 길**
= **정견에서 정정까지**

현존 경문은 같은 구조를,

### 퇴보의 길·더 나은 길
### 낮은 길·높은 길
### 여러 길과 자취

에도 적용한다고 압축합니다.

## 왜 팔정도가 ‘역류’인가

세상의 습관은 쉽게,

# **좋아하는 것은 붙잡고**
# **싫어하는 것은 밀어내고**
# **내 견해를 나로 만들며**
# **편한 쪽으로 흘러갑니다.**

팔정도는 그 자동 흐름을 거슬러,

# **사실을 보고**
# **해치지 않고**
# **바르게 말하고 행동하며**
# **마음을 훈련합니다.**

[주의]

역류를,

# **무조건 사회 규범에 반항하는 것**

으로 해석하지 않습니다.

탐·진·치의 자동 흐름을 거스르는 수행 비유입니다.

---

# 제794경 — 사문은 옷이 아니라 팔정도를 갖춘 사람

부처님은 묻습니다.

# **사문의 법이 무엇인가?**

답은,

# **팔정도**

입니다.

그러면 누가 사문입니까?

# **이 법을 성취한 사람이 사문**

입니다.

---

## [주의] 출가 옷을 입으면 자동으로 사문인가

제794경은 오히려,

# **사문의 기준을 실제 법의 성취**

에 둡니다.

형식과 신분보다,

# **정견에서 정정까지 실제 삶에 있는가**

가 중요합니다.

---

# 제795경 — 사문의 ‘뜻’은 탐·진·치의 완전한 소멸

사문의 법은 다시,

# **팔정도**

입니다.

사문의 뜻·목적은,

# **탐욕이 영원히 다하고**
# **성냄이 영원히 다하며**
# **어리석음이 영원히 다하고**
# **모든 번뇌가 다하는 것**

입니다.

즉 팔정도는,
종교적 정체성을 만드는 길이 아니라,

# **번뇌를 끝내는 길**

입니다.

---

# 제796경 — 사문의 과는 네 성자의 과

사문의 법은,

# **팔정도**

이고,

그 과는,

# **수다원과**
# **사다함과**
# **아나함과**
# **아라한과**

입니다.

제28권은 이렇게,
팔정도의 첫빛인 정견에서 시작해,

# **네 성자의 과**

로 끝납니다.

---

# 제790~796경 전체 요약

팔정도는,

# **악취와 생사의 흐름에서 벗어나는 길**
# **십선의 삶과 연결되는 길**
# **탐·진·치의 자동 흐름을 거스르는 길**
# **사문의 법**
# **성자의 과를 낳는 길**

입니다.

그리고 한 걸음 더 나아가,

# **팔정도 자체도 세속적 층위와 출세간의 성스러운 층위**

괴로움의 끝까지 정밀하게 설명합니다.

# 제1~28권의 흐름

## 제1권
오온을 왜 나·내 것으로 붙잡을 수 없는가

## 제2권
왜 그래도 계속 오온을 나라고 붙잡는가

## 제3권
자기화는 어떤 조건으로 생기고 사라지는가

## 제4권
그 가르침을 이해한 사람은 세상 속에서 어떻게 살아야 하는가

## 제5권
무아 이해 뒤에도 남는 미세한 ‘나는’과 해탈의 오해

## 제6권
수행의 목적과 괴로움의 흐름을 어떻게 끝내는가

## 제7권
자아견에서 여러 철학적 견해가 어떻게 생기고 수행 전체로 어떻게 끊는가

## 제8권
감각 경험에서 접촉·느낌·갈애·취착이 어떻게 생기는가

## 제9권
감각기관과 대상 자체가 아니라 욕탐이 결박임을 알고 감각문을 지키는 법

무명이 무엇인지 밝히고 연기의 중도와 밝은 앎을 닦는 법

## 제11권
보고 듣되 좋아함과 싫어함에 끌려가지 않는 감각수호

## 제12권
괴로움의 조건 사슬 전체와 유·무 두 극단을 떠난 연기의 중도

## 제13권
육육법으로 감각 경험을 해부하고 ‘사람·나’라는 명칭·업·공·평형까지 연결

## 제14권
연기의 앎을 정견·법주지·혜해탈·44지·77지로 정밀화

## 제15권
네 가지 음식과 사성제를 통해 괴로움의 공급·진단·소멸·길을 통합

## 제16권
주의력·동류 성향·18계와 접촉→느낌→갈애→추구의 조건을 살핌

## 제17권
느낌을 집중 분석해 두 번째 화살과 맛·위험·벗어남을 배움

## 제18권
팔정도·계율·갈등 해결·확신·정명·삼매·정진으로 수행 생활 전체를 점검

## 제19권
업·재생 과보 서사를 읽되 피해자 비난을 피하고 사념처라는 현재 수행으로 돌아옴

## 제20권
사념처를 해탈까지 확장하고 갈등·신분·육념·감각의 흐름·무상심삼매를 살핌

## 제21권
선한 의욕을 사용하고 놓는 구조, 네 청정, 질다 장자의 삼매·신견·욕탐 결박을 살핌

## 제22권
천신·재가자 전승 속에서 무상·세속가명·연기·귀의·불방일을 살핌

## 제23권
아소카왕의 장편 전승을 통해 폭력에서 참회·자비·불법 외호로의 전환을 살핌

## 제24권
사념처를 중심으로 계·감각수호·자타보호·해탈을 통합하고 자등명·법등명으로 마무리

## 제25권
정법 쇠퇴와 아소카의 마지막 보시를 통해 법의 제도와 왕권의 조건성과 무상을 살핌

## 제26권
오근·오력·여러 수행의 힘을 정리하고 번뇌와 청정 모두 조건이 있음을 확인

## 제27권
오개와 칠각지의 먹이·균형·정사유·선지식을 통해 깨달음 요소를 실제로 조절하는 법을 살핌

## 제28권
# **정견을 괴로움의 끝을 알리는 첫빛으로 세우고, 대상 자체가 아니라 탐착이 욕망임을 분명히 한 뒤, 노·병·사라는 누구도 대신할 수 없는 문제 앞에서 팔정도를 길로 제시하며, 바른 사유와 좋은 벗이라는 안팎의 조건을 통해 팔정도를 키우고, 세속적 바른 길에서 사성제를 직접 관찰하는 출세간의 바른 길로 깊어져 탐·진·치의 소멸과 네 성자의 과에 이르는 구조를 보여 주는 권**

제748경.

## ③ 재가자든 출가자든 팔정도의 바른 방향은 공통된다
제751경.

제752경.

## ⑤ 바른 삼매는 나머지 일곱 팔정도 요소 위에 서는 삼매다
제754~757경.

제758경.

제760경.

제768경.

## ⑩ 내부에서는 바른 사유, 외부에서는 좋은 벗이 그릇된 길을 줄이고 팔정도를 키운다
제775~781경.

## ⑪ 팔정도에는 선처로 향하는 세속적 층위와 사성제를 직접 관찰해 괴로움을 끝내는 성스러운 출세간 층위가 있다
제784~789경.

## ⑫ 사문의 법은 팔정도이고, 사문의 뜻은 탐·진·치와 모든 번뇌의 소멸이며, 그 과는 네 성자의 과다
제794~796경.

# [주의] 제28권에서 생기기 쉬운 대표 오해

## “정견이 먼저니 나머지 수행은 필요 없다”

아닙니다.

정견은,

# **나머지 일곱 요소를 바른 방향으로 일으키는 첫빛**

입니다.

팔정도 전체가 필요합니다.

---

## “욕망을 끊으려면 아름다운 대상부터 없애야 한다”

제752경이 직접 반박합니다.

# **대상 자체가 욕망이 아니라 탐착이 욕망**

입니다.

---

## “부모도 죽음을 막아 줄 수 없으니 가족관계는 무의미하다”

제758경의 뜻이 아닙니다.

가족은 서로 돌보고 사랑할 수 있지만,

# **노·병·사를 완전히 대신 살아 줄 수는 없다**

는 사실을 말합니다.

---

## “팔정도를 닦으면 늙지도 병들지도 죽지도 않는다”

아닙니다.

팔정도의 목적은 생물학적 불사를 만드는 것이 아니라,

# **노·병·사에 대한 갈애·취착과 생사의 괴로움을 끝내는 것**

입니다.

---

## “좋은 벗이 전부라면 스승에게 의존하기만 하면 된다”

아닙니다.

좋은 벗은,

# **정견과 팔정도를 실제로 닦게 하는 조건**

입니다.

대신 수행해 주는 사람이 아닙니다.

---

## “제769경에 대승이라고 있으니 대승불교를 말한다”

이 문맥의 `大乘`은,

# **팔정도를 ‘큰 수레’로 비유한 표현**

입니다.

후대 대승불교의 교명과 자동 동일시하지 않습니다.

---

## “세속적 정견은 낮고 쓸모없는 가르침이다”

제785경은 세속적 정견을,

# **선처로 향하는 바른 견해**

라고 합니다.

윤리와 선행의 토대입니다.

다만 해탈에는 사성제를 직접 아는 출세간 지혜가 더 필요합니다.

---

## “정견이 있으면 모든 좋은 일이 자동으로 생긴다”

제787~788경의 씨앗 비유는
기본 방향이 행동에 큰 영향을 준다는 뜻입니다.

현실의 모든 사건을,

# **한 사람의 견해 하나로 기계적으로 설명**

하지 않습니다.

---

## “지옥·아귀·천상 전승을 믿지 않으면 정견이 불가능하다”

제784~785경의 세속 정견에는
업·재생 전승이 실제로 포함됩니다.

이 프로젝트에서는 이를 삭제하지 않습니다.

그러나 독자에게 사실 믿음을 강요하지도 않습니다.

초기불교가 **어떤 세계관 속에서 윤리와 수행을 설명했는지** 정확히 보존합니다.

---

## “역류의 길은 사회에 무조건 반항하는 것”

제793경의 역류는,

# **탐·진·치와 그릇된 견해의 자동 흐름을 거스르는 수행**

입니다.

정치적·사회적 반항 그 자체를 뜻하지 않습니다.

# **기본적으로 무엇을 사실이라고 보고 어떤 방향에 서 있는지가 이후의 생각·말·행동을 조직한다**

고 설명합니다.

호킨스 박사님의 언어로 제한적으로 비교하면,
**위치성이 이후의 지각과 선택을 조직할 수 있다**는 설명과 비교할 여지가 있습니다.

제752경은 더 흥미롭습니다.

# **대상 자체보다 그 대상에 붙는 탐착이 결박**

이라는 점은,
내용 그 자체보다 **그 내용과의 동일시·집착 방식**을 보는 언어와 제한적으로 연결할 수 있습니다.

제775~780경의,

# **안에서는 바른 사유**
# **밖에서는 좋은 벗**

이라는 구조도,
내적 태도와 외적 맥락이 함께 마음의 방향에 영향을 준다는 점에서 비교할 수 있습니다.

# **사성제를 직접 관찰하고 괴로움의 끝을 향하는 지혜**

로 설명해야 합니다.

# 제28권 최종 정리

『잡아함경』 제28권은,
팔정도를 다시 처음부터 묻습니다.

첫 질문은,

# **“무엇이 먼저인가?”**

입니다.

부처님은 해가 뜨기 전
첫빛이 먼저 보이는 것처럼,

# **정견이 먼저 길을 밝힌다**

고 합니다.

정견이 서면,
생각과 말과 행동과 생계와 정진과 마음챙김과 삼매가
그 방향을 따라갑니다.

제749~750경은 그 반대도 보여 줍니다.

무명이 있으면,
잘못을 부끄러워하지 않고
그릇된 견해가 자랍니다.

그 견해가,
생각과 말과 행동 전체를 끌고 갑니다.

그래서 수행의 첫 질문은,

# **“나는 무엇을 사실이라고 보고 있는가?”**

입니다.

그런데 제752경은
욕망에 관해 매우 중요한 오해를 풀어 줍니다.

아름다운 색,
좋은 소리,
향기,
맛,
촉감이 있습니다.

하지만 부처님은,

# **“그것들이 욕망 자체는 아니다.”**

라고 합니다.

# **그것에 탐착하는 마음이 욕망입니다.**

이 한 문장은
감각수호를 세상혐오로 만드는 것을 막아 줍니다.

세상을 없애는 것이 아니라,
세상과 만날 때 탐착이 어떻게 붙는지 봅니다.

제758경에서는 더 근본적인 현실이 나옵니다.

전쟁이 나면 가족이 헤어질 수 있습니다.
화재와 홍수도 그렇습니다.

하지만 다시 만날 수도 있습니다.

반면,

# **늙음**
# **질병**
# **죽음**

은 누구도 대신해 줄 수 없습니다.

어머니가 자식 대신 늙을 수 없고,
자식이 어머니 대신 죽을 수 없습니다.

이것이 초기불교가 문제를 시작하는 자리입니다.

# **누구도 대신해 줄 수 없는 삶의 조건 앞에서**
# **마음을 어떻게 훈련할 것인가.**

그 답이 팔정도입니다.

중반 제768경부터는,
이 길이 혼자 자라지 않는다고 합니다.

아난다는 좋은 벗이 수행의 절반이라고 생각하지만,
부처님은,

# **“절반이 아니라 전체다.”**

라고 합니다.

좋은 벗은 팔정도를 대신 살아 주는 사람이 아닙니다.

하지만,

# **무엇을 바른 것으로 배우고**
# **어떤 행동을 정상이라고 여기며**
# **어느 방향으로 정진할지**

에 큰 영향을 줍니다.

안에서는,

# **바른 사유**

가 중요합니다.

밖에서는,

# **좋은 벗**

이 중요합니다.

제784~789경은
팔정도의 깊이를 더 정밀하게 나눕니다.

세속적 정견은,
보시와 선악의 결과를 인정하고
바른 말·행동·생계를 닦아
건전한 삶으로 향하게 합니다.

그러나 초기불교의 길은 거기서 멈추지 않습니다.

성스러운 출세간 정견은,

# **괴로움**
# **괴로움의 원인**
# **괴로움의 소멸**
# **소멸로 가는 길**

을 직접 관찰합니다.

그래서 팔정도는,

# **좋은 사람이 되는 길**
인 동시에,

# **괴로움의 구조를 직접 보고 집착을 끝내는 길**

입니다.

마지막에는 이 길을,

# **흐름을 거슬러 가는 길**

이라고 부릅니다.

세상의 자동 습관은,
좋으면 붙잡고
싫으면 밀어내며
자기 견해를 지키려고 합니다.

팔정도는 그 자동 흐름을 거슬러,

# **바르게 보고**
# **해치지 않고**
# **바르게 말하고 행동하며**
# **마음을 훈련합니다.**

그래서 사문의 법은 팔정도이고,
사문의 뜻은,

# **탐욕·성냄·어리석음과 모든 번뇌의 소멸**

이며,
그 과는,

# **수다원**
# **사다함**
# **아나함**
# **아라한**

이라고 제28권은 끝맺습니다.

# 제28권을 한 문장으로

# **『잡아함경』 제28권은 정견을 괴로움의 끝을 알리는 해 뜨기 전 첫빛으로 세우고, 무명과 밝은 앎이 각각 사도와 팔정도를 연쇄적으로 일으킨다고 설명하며, 감각 대상 자체가 아니라 탐착이 욕망임을 분명히 한 뒤, 부모자식도 대신해 줄 수 없는 노·병·사 앞에서 팔정도를 길로 제시한다. 이어 바른 사유와 좋은 벗이라는 안팎의 조건으로 팔정도를 키우고, 세속적 바른 삶에서 사성제를 직접 관찰하는 성스러운 출세간의 바른 길로 깊어져, 마지막에는 탐·진·치의 흐름을 거슬러 네 성자의 과와 괴로움의 끝에 이르는 길로 팔정도를 완성한다.**
