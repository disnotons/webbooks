# 『잡아함경 쉬운 완전읽기』 제17권
## 느낌은 왜 두 번째 화살이 되는가 — 계(界)·지관·라훌라의 무아관·삼수·맛과 위험·108수

> **범위:** 『잡아함경』 제17권, 제455경~제489경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』  
> **수록 경수:** **35경**  
> **읽기 방식:** 이번 권은 앞 권의 `界` 논의를 이어 받아 **감각 조건이 어떻게 접촉·인식·욕구·추구로 자라는지**, 그리고 `界`가 수행의 여러 층위에서 어떻게 쓰이는지를 살핀다. 이어 제465경부터는 중심이 **느낌(受)**으로 옮겨 간다. 즐거움·괴로움·불고불락의 느낌을 어떻게 보아야 하는지, 왜 범부는 ‘두 번째 화살’을 맞고 성스러운 제자는 한 화살에서 멈추는지, 느낌의 **집·멸·맛·위험·벗어남**이 무엇인지 집중적으로 설명한다.

---

# 한 문장 핵심

『잡아함경』 제17권은 이렇게 정리할 수 있습니다.

# **감각과 마음의 여러 조건은 서로 다른 접촉·인식·욕구·행동을 낳으며, 느낌 자체보다 느낌을 탐욕·성냄·어리석음으로 붙잡는 것이 괴로움을 더한다. 즐거운 느낌도 변하고, 괴로운 느낌도 조건에 따라 생기며, 평온한 느낌도 무상하므로 세 느낌을 사실대로 알아 탐·진·치의 잠재적 힘을 끊을 때 ‘두 번째 화살’이 사라지고 해탈로 향한다.**

이번 권의 큰 흐름은 다음과 같습니다.

# **계(界)**
→ **접촉**
→ **인식**
→ **욕구**
→ **생각**
→ **달아오름**
→ **추구**

이어 느낌에서는,

# **접촉**
→ **느낌**

그 느낌을 모르면,

# **즐거움 → 탐**
# **괴로움 → 성냄**
# **불고불락 → 어리석음**

이 붙습니다.

반대로,

# **느낌의 발생·소멸·맛·위험·벗어남을 사실대로 앎**
→ **탐·진·치의 지배가 약해짐**
→ **한 화살에서 멈춤**
→ **염·이욕·멸**
→ **해탈**

입니다.

## 여러 `界`를 어떻게 이해할 것인가 — 감각 요소·성향·삼계·출계·지관과 해탈

# 제455경 — 계에서 추구까지의 방향을 다시 확인한다

제455경은 제16권 마지막 제454경과 거의 같은 구조를 반복합니다.

# **여러 계**
→ **여러 접촉**
→ **여러 인식**
→ **여러 욕구**
→ **여러 생각**
→ **여러 달아오름**
→ **여러 추구**

입니다.

그리고 이 방향을 거꾸로 뒤집지 말라고 거듭 강조합니다.

예를 들어,

# **안계가 조건이 되어 안촉이 생기고**
# **안촉이 조건이 되어 안상이 생기며**
# **안상이 조건이 되어 안욕이 생기고**
# **안욕이 조건이 되어 안각·안열·안구가 생깁니다.**

[주의]

제455경의 `覺`은 문맥상 **생각·사유**입니다.

`깨달음`으로 옮기면 전체 연쇄가 이상해집니다.

---

# 제456경 — 빛·정화·무색정·멸의 ‘계’

부처님은 여러 계를 말합니다.

### 광계
### 정계
### 무량공입처계
### 무량식입처계
### 무소유입처계
### 비상비비상입처계
### 멸계

한 비구가 묻습니다.

> **“이 여러 계는 무엇을 조건으로 알 수 있습니까?”**

부처님은 서로 대비되는 조건을 들어 설명합니다.

### 빛은 어둠을 조건으로 알아지고
### 깨끗함은 더러움을 조건으로 알아지고
### 무량공은 색을 조건으로
### 무량식은 안을 조건으로
### 무소유는 소유를 조건으로
### 비상비비상은 앞선 존재 상태를 조건으로
### 멸은 ‘몸이 있음’을 조건으로 알아진다고 설명합니다.

이어 이런 계들이 **정수(正受), 즉 삼매의 성취**와 연결됨을 말합니다.

[주의]

여기의 `界`를 모두 하나의 동일한 실체나 ‘우주 차원’으로 묶지 않습니다.

현존 경문은 서로 다른 수행·경험 범주를 `界`라는 말로 표현합니다.

---

# 제457경 — 말·견해·상상도 어떤 계를 조건으로 생긴다

부처님은 말합니다.

# **말도 계를 조건으로 생기고**
# **견해도 계를 조건으로 생기며**
# **상도 계를 조건으로 생깁니다.**

낮은 계를 조건으로 하면,

### 낮은 말
### 낮은 견해
### 낮은 생각
### 낮은 욕구
### 낮은 소원
### 낮은 행위
### 낮은 태어남

이 생긴다고 합니다.

높은 계도 마찬가지입니다.

바깔리 비구가 묻습니다.

> **“정등각자를 정등각자가 아니라고 보는 잘못된 견해도 계를 조건으로 생깁니까?”**

부처님은 그렇다고 합니다.

그리고 그 배경으로,

# **범부의 계 = 무명의 계**

라는 말을 합니다.

---

## [연결] 견해도 갑자기 생기는 것이 아니다

제457경은,

# **견해와 말도 마음의 조건과 성향을 먹고 자란다**

는 점을 보여 줍니다.

앞 권의,

# **선한 마음은 선한 계와 함께하고**
# **불선한 마음은 불선한 계와 함께한다**

는 내용과 연결됩니다.

---

# 제458경 — 욕망·성냄·해침도 원인 없이 생기지 않는다

부처님은 분명히 말합니다.

# **욕상은 원인 없이 생기지 않는다.**
# **성냄과 해치려는 생각도 원인 없이 생기지 않는다.**

욕계를 조건으로,

# **욕상**
→ **욕구**
→ **욕각**
→ **달아오름**
→ **추구**

가 생깁니다.

무지한 사람이 그 추구를 따라가면,

# **몸·말·마음의 그릇된 행위**

가 생기고,
현생의 괴로움과 전승상 악처의 결과로 이어진다고 합니다.

반대로,

### 출요계
### 불성냄
### 불해침

의 조건에서는,

# **출요의 생각**
# **불해의 생각**
# **바른 몸·말·마음의 행위**

가 생깁니다.

[전승]

악처·선처의 재생은 현존 경전의 전승 요소입니다.

이를 지우지 않되 믿음을 강요하지 않습니다.

---

# 제459경 — 자작·타작을 단순한 둘 중 하나로 고정하지 않는다

한 바라문이,

> **“중생은 스스로 만드는 것도 아니고 남이 만드는 것도 아닙니까?”**

라고 묻습니다.

부처님은 이런 단정적 논의에 곧바로 동의하지 않습니다.

대신,

### 방편계
### 안주계
### 견고계
### 출계
### 조작계

같은 조건을 물으며,

# **중생에게 방편과 조작을 알게 하는 조건이 실제로 있다**

는 쪽으로 논의를 돌립니다.

이 경은 매우 짧고 난해합니다.

[주의]

따라서 이를,

> **“모든 것은 자유의지다.”**
또는
> **“모든 것은 타력이다.”**

라는 현대적 논쟁의 한쪽 답으로 단순화하지 않습니다.

직접 확인되는 것은,

# **행동과 방편에도 조건이 있다는 점**

입니다.

---

# 제460경 — 기쁨·근심·평형의 접촉

구사라 장자가 아난다에게,

> **“여러 계란 무엇입니까?”**

라고 묻습니다.

아난다는 눈과 색을 예로 들어,

# **눈의 계 + 색의 계**
→ **의식**
→ **접촉**

을 설명합니다.

그 접촉이 기쁨의 자리라면,

# **즐거운 느낌**

괴로움의 자리라면,

# **괴로운 느낌**

평형의 자리라면,

# **불고불락의 느낌**

이 생깁니다.

귀·코·혀·몸·마음도 같습니다.

---

# 제461경 — 삼계: 욕계·색계·무색계

아난다는 세 계를 말합니다.

# **욕계**
# **색계**
# **무색계**

게송은 이 세 영역을 알고,
모든 남은 존재를 놓아,

# **남김없는 적멸**

로 향하는 방향을 말합니다.

[전승]

욕계·색계·무색계는 초기불교 경전의 세계관·수행 분류 요소입니다.

현대 우주의 물리적 차원과 동일시하지 않습니다.

---

# 제462경 — 색계·무색계·멸계

다른 문답에서는,

# **색계**
# **무색계**
# **멸계**

세 가지를 듭니다.

게송은 색계와 무색계에 머물더라도,

# **멸계를 알지 못하면 다시 존재를 받는다**

고 하고,

# **멸계에서 마음이 해탈하면 생사를 떠난다**

는 방향으로 끝납니다.

[주의]

`滅界`를 어떤 영원한 실체적 세계로 자동 해석하지 않습니다.

문맥상 **행과 집착의 소멸·해탈**과 연결되어 있습니다.

---

# 제463경 — 세 가지 출계

아난다는 이번에는,

# **욕계에서 벗어나 색계로**
# **색계에서 벗어나 무색계로**
# **모든 행과 생각의 멸로**

향하는 세 출계를 말합니다.

게송의 결론은,

# **모든 갈애를 끊고**
# **모든 행을 멸하여**
# **다시 유로 돌아가지 않는 것**

입니다.

---

# 제464경 — 지와 관은 서로 완성한다

아난다가 한 상좌에게 묻습니다.

> **“숲·나무 아래·한적한 방에서 무엇을 전념해 닦아야 합니까?”**

답은 두 가지입니다.

# **止 — 지**
# **觀 — 관**

아난다는 다시 묻습니다.

> **“지를 많이 닦으면 무엇이 완성되고, 관을 많이 닦으면 무엇이 완성됩니까?”**

상좌는,

# **지를 닦으면 관이 완성되고**
# **관을 닦으면 지도 완성되며**
# **성스러운 제자는 지와 관을 함께 닦아 여러 해탈계를 얻는다**

고 말합니다.

---

## 세 해탈계

### 단계(斷界)
# **모든 행을 끊음**

### 무욕계(無欲界)
# **갈애를 끊음**

### 멸계(滅界)
# **모든 행의 멸**

입니다.

아난다는 500비구에게도 같은 질문을 하고,
부처님에게도 같은 질문을 합니다.

# **상좌·500비구·부처님의 답이 같은 뜻·같은 문장·같은 맛**

이었다고 감탄합니다.

부처님은 그 상좌와 500비구 모두 **아라한**이라고 밝힙니다.

---

## [주의] 지와 관은 서로 적이 아니다

제464경은,

# **지냐 관이냐 하나를 선택하는 논쟁**

으로 읽기 어렵습니다.

경은 오히려,

# **지와 관이 서로를 완성하고 함께 해탈로 향한다**

고 말합니다.

---

# 제455~464경 전체 요약

이번 경군의 `界`는 한 가지 뜻만 갖지 않습니다.

### 감각 요소의 계
### 마음의 성향과 견해를 조건 짓는 계
### 욕·색·무색의 존재 영역
### 멸·출요·해탈의 계

등 여러 문맥이 나옵니다.

따라서,

# **`界`를 무조건 ‘세계’나 ‘장(field)’이라고 번역하지 않고 문맥마다 기능을 확인해야 합니다.**

그리고 끝에서는,

# **지와 관을 함께 닦아 갈애와 행의 소멸로 향한다**

는 수행으로 연결됩니다.

# 제465경 — 몸과 바깥 경계의 모든 상에서 ‘나·내 것·아만’을 놓다

라훌라는 묻습니다.

> **“어떻게 알고 보아야 이 식신과 바깥 경계의 모든 상에서 나·내 것이라는 견해와 아만의 결박이 없어집니까?”**

부처님은,

### 지계
### 수계
### 화계
### 풍계
### 공계
### 식계

를 과거·미래·현재,
안·밖,
거칠고 미세함,
좋고 나쁨,
멀고 가까움 전체에 대해,

# **나가 아니고**
# **나와 다른 고정 자아도 아니며**
# **서로 안에 들어 있는 자아도 아니라고 사실대로 알라**

고 합니다.

그렇게 보면,

# **나·내 것이라는 견해**
# **아만**
# **결박과 잠재 번뇌**

가 끊어지고,
괴로움의 끝에 이릅니다.

---

## [주의] 식계가 마지막 참자아인가

아닙니다.

제465경은,

# **지·수·화·풍·공뿐 아니라 식계도 같은 방식으로 비아로 관찰**

합니다.

따라서,

> **“물질은 무아지만 식계는 참된 관찰자다.”**

라고 읽을 수 없습니다.

---

# 제466경 — 느낌은 접촉을 조건으로 생긴다

라훌라에게 이번에는 세 느낌을 가르칩니다.

# **고수**
# **낙수**
# **불고불락수**

부처님은 묻습니다.

> **“이 세 느낌은 무엇을 원인으로 하고 무엇에서 생기는가?”**

답은,

# **접촉**

입니다.

# **접촉이 생기면 그에 따른 느낌이 생기고**
# **접촉이 멸하면 그 느낌도 멸하고 식고 가라앉습니다.**

이렇게 아는 것이,
식신과 외부 경계를 나·내 것으로 붙잡지 않는 데 연결됩니다.

---

# 제467경 — 세 느낌을 어떻게 관찰할 것인가

부처님은,

# **즐거운 느낌에서는 ‘괴로움의 성질’을 보고**
# **괴로운 느낌에서는 ‘칼에 찔리는 것’을 보고**
# **불고불락에서는 무상·멸을 보라**

고 합니다.

[주의]

# **즐거움을 느끼면 죄라고 생각하라는 뜻이 아닙니다.**

즐거운 느낌이,

# **변하고 사라지며 붙잡으면 괴로움이 될 수 있다는 성질**

을 보라는 것입니다.

괴로운 느낌은 실제로 찌르는 듯한 압박을 갖고,
불고불락은 무심히 지나치기 쉬우므로 **무상성과 소멸**을 분명히 봅니다.

---

# 제468경 — 세 느낌과 탐·진·치의 잠재적 힘

부처님은 수행 목적을 더 직접적으로 말합니다.

# **즐거운 느낌에서 탐욕의 잠재적 힘을 끊기 위해**
# **괴로운 느낌에서 성냄의 잠재적 힘을 끊기 위해**
# **불고불락에서 어리석음의 잠재적 힘을 끊기 위해**

범행을 닦습니다.

즉,

# **낙수 ↔ 탐**
# **고수 ↔ 진**
# **불고불락 ↔ 치**

가 자동적이고 고정된 동일식은 아니지만,
각 느낌에서 대표적으로 자라기 쉬운 결박을 경계합니다.

---

## 느낌을 ‘알아차리는 것’이 중요하다

게송은,

# **즐거운 느낌을 느끼면서도 제대로 알지 못하면 탐에 휘둘리고**
# **괴로운 느낌을 제대로 알지 못하면 성냄에 휘둘리며**
# **불고불락을 잘 관찰하지 않으면 저 언덕을 건너지 못한다**

고 합니다.

반대로 모든 느낌을 지혜로 알면,

# **현법에서 누를 다하는 방향**

으로 갑니다.

---

# 제3경군 — 제469~474경
## 괴로운 느낌은 왜 ‘두 번째 화살’이 되는가

이 경군은 초기불교의 느낌 이해에서 가장 유명한 부분 가운데 하나입니다.

---

# 제469경 — 진짜 깊은 바다는 몸에서 생기는 괴로운 느낌일 수 있다

세상 사람은 큰 바다를 깊고 위험하다고 말합니다.

부처님은,

# **성스러운 법과 율에서 더 깊고 위험한 바다는 몸에서 생겨 사람을 압박하는 괴로운 느낌**

이라고 합니다.

무지한 사람은 고통이 닥치면,

### 근심하고
### 슬퍼하고
### 울고
### 비명을 지르고
### 마음이 어지러워지고

그 결과,

# **괴로움을 더 모아 생사의 바다에 가라앉습니다.**

성스러운 제자는 몸의 괴로운 느낌이 있어도,

# **그 위에 우·비·광란을 더하지 않아 머물 곳을 얻습니다.**

---

# 제470경 — 두 번째 화살

제470경은 이번 권의 핵심 경입니다.

부처님은 묻습니다.

# **범부도 즐거움·괴로움·불고불락을 느끼고**
# **성스러운 제자도 똑같이 세 느낌을 느낀다.**

그렇다면 차이는 무엇일까요?

---

## 범부 — 두 개의 독화살을 맞는다

몸의 괴로운 접촉이 생기면,
범부는 실제 신체적 고통에 더해,

### 근심
### 원망
### 울음
### 비명
### 마음의 혼란

을 일으킵니다.

부처님은 비유합니다.

[비유]

# **첫 번째 독화살에 맞은 뒤 두 번째 독화살까지 맞는 것**

입니다.

첫 화살은,

# **몸의 고통**

두 번째 화살은,

# **그 고통에 대한 마음의 추가 반응**

입니다.

---

## 성스러운 제자 — 한 화살에서 멈춘다

성스러운 제자도,

# **몸의 괴로운 느낌은 느낍니다.**

그러나,

# **마음의 두 번째 괴로움을 추가하지 않습니다.**

따라서 한 화살만 맞는 것과 같습니다.

---

## 즐거움에서도 차이가 난다

범부는 즐거운 느낌을 만나면,

# **감각적 즐거움에 물들어 탐욕에 지배**

될 수 있습니다.

괴로운 느낌에는 성냄,
불고불락에는 어리석음에 지배됩니다.

왜냐하면,

# **느낌의 집·멸·맛·위험·벗어남을 사실대로 모르기 때문**

입니다.

성스러운 제자는 이를 사실대로 알기에,

# **탐·진·치의 지배에서 풀려납니다.**

---

## [주의] “수행자는 아파도 아무렇지 않아야 한다”?

아닙니다.

제470경은 분명히,

# **성스러운 제자도 몸의 괴로운 느낌을 느낀다**

고 합니다.

수행의 차이는,

# **통증 자체가 없어지는가**
보다
# **그 통증 위에 원망·두려움·자기연민·증오를 얼마나 더 쌓는가**

에 있습니다.

---

# 제471경 — 느낌은 바람처럼 다양하게 일어난다

[비유]

허공에는,

### 먼지바람
### 맑은 바람
### 약한 바람
### 강한 바람
### 여러 방향의 바람

이 일어납니다.

몸에서도 마찬가지로 여러 느낌이 생깁니다.

### 낙·고·불고불락
### 몸의 느낌
### 마음의 느낌
### ‘먹이가 있는’ 느낌
### ‘먹이가 없는’ 느낌
### 탐착과 연결된 느낌
### 출요와 연결된 느낌

등입니다.

핵심은,

# **느낌은 하나의 고정된 실체가 아니라 여러 조건에 따라 다양하게 일어나는 사건**

이라는 것입니다.

---

# 제472경 — 몸은 여러 느낌이 머무는 객사와 같다

[비유]

객사에는,

### 왕족
### 바라문
### 장자
### 사냥꾼
### 계를 지키는 사람
### 계를 어기는 사람
### 재가자
### 출가자

등 여러 사람이 드나듭니다.

몸도 마찬가지로,

# **여러 종류의 느낌이 잠시 생겨 머물다 사라지는 곳**

입니다.

[연결]

이 비유는 느낌을,

> **“나의 본질”**

이라고 굳히는 대신,

# **왔다가 가는 손님처럼 관찰**

하게 도와줍니다.

---

# 제473경 — “모든 느낌은 괴롭다”의 정확한 뜻

한 비구가 고민합니다.

> **“부처님은 세 느낌, 즉 즐거움·괴로움·불고불락을 말하면서 왜 또 모든 느낌이 괴롭다고 합니까?”**

부처님은 답합니다.

# **모든 행이 무상하고 변하는 법이기 때문에**
# **모든 느낌을 괴로움이라고 말한다.**

---

## [주의] 즐거운 느낌이 실제로 ‘아픈 느낌’이라는 뜻이 아니다

아닙니다.

제473경은 세 느낌의 차이를 지우지 않습니다.

즐거움은 즐거운 느낌으로 인정합니다.

그런데,

# **그 즐거움조차 무상하고 변하여 안정적으로 붙잡을 수 없다는 점**

에서 `고`의 성질을 말합니다.

따라서,

# **“기분 좋은 것도 사실은 아프다.”**

라고 억지 번역하지 않습니다.

---

# 제474경 — 모든 느낌이 괴롭다는 말과 점차적 적멸

아난다도 같은 질문을 합니다.

부처님은 제473경의 설명을 반복하면서,
이번에는 **점차적 행의 적멸**을 더합니다.

### 초선
→ **말이 고요해짐**

### 이선
→ **각·관이 고요해짐**

### 삼선
→ **희가 고요해짐**

### 사선
→ **들숨날숨이 고요해짐**

### 공입처
→ **색상이 고요해짐**

### 식입처
→ **공입처상이 고요해짐**

### 무소유입처
→ **식입처상이 고요해짐**

### 비상비비상입처
→ **무소유입처상이 고요해짐**

### 상수멸정
→ **상과 수가 고요해짐**

이라고 합니다.

---

## 가장 뛰어난 고요는 무엇인가

부처님은 더 높은 고요를 말합니다.

# **탐욕에서 마음이 벗어나고**
# **성냄에서 마음이 벗어나며**
# **어리석음에서 마음이 벗어나는 것**

입니다.

이를,

# **가장 뛰어나고 기이하며 위없는 고요**

라고 합니다.

[주의]

선정 단계 자체를 무의미하게 만들지 않습니다.

제474경은 오히려 **점차적 고요를 구체적으로 인정**하면서,
최종적으로는 **탐·진·치의 해탈**을 최상으로 둡니다.

---

# 제469~474경 전체 요약

# **느낌은 사라져야 할 적이 아닙니다.**

범부와 성자 모두 느낌을 경험합니다.

차이는,

# **느낌 위에 탐·진·치와 자기 이야기를 얼마나 더 붙이는가**

입니다.

즐거움도 무상하고,
괴로움도 조건에 따라 생기며,
평온한 느낌도 변합니다.

# **그 사실을 알아 두 번째 화살을 만들지 않는 것**

이 핵심입니다.

---

# 제4경군 — 제475~480경
## 느낌을 완전히 안다는 것은 무엇인가 — 집·멸·길·맛·위험·벗어남

---

# 제475경 — 과거불도 느낌을 이렇게 관찰했다는 전승

비바시불이 정각 이전에 묻습니다.

# **느낌이란 무엇인가?**
# **느낌의 집은 무엇인가?**
# **느낌의 멸은 무엇인가?**
# **느낌의 집으로 가는 길은?**
# **느낌의 멸로 가는 길은?**
# **느낌의 맛은?**
# **느낌의 위험은?**
# **느낌에서 벗어남은?**

답은 다음과 같습니다.

### 느낌
# **낙수·고수·불고불락수**

### 느낌의 집
# **접촉의 집**

### 느낌의 멸
# **접촉의 멸**

### 느낌의 집으로 가는 길
# **느낌을 사랑하고 칭찬하고 물들어 굳게 머무는 것**

### 느낌의 멸로 가는 길
# **느낌을 그렇게 사랑·칭찬·염착해 머물지 않는 것**

### 느낌의 맛
# **느낌을 조건으로 생기는 즐거움과 기쁨**

### 느낌의 위험
# **느낌이 무상하고 변하는 법이라는 것**

### 느낌에서 벗어남
# **느낌에 대한 욕탐을 끊고 넘어서는 것**

입니다.

---

## [주의] 느낌의 맛을 부정하지 않는다

경은,

# **즐거운 느낌의 맛이 실제로 있다**

고 인정합니다.

그래서 사람들이 거기에 붙습니다.

초기불교는,

> **“즐거움은 전부 가짜다.”**

라고 말하는 것이 아니라,

# **맛이 있지만 위험도 있고 벗어남도 있다는 전체 구조**

를 봅니다.

---

# 제476경 — 한 비구가 직접 느낌을 분석하다

한 비구가 홀로 명상하며 제475경과 똑같은 질문을 합니다.

부처님은 같은 구조로 답합니다.

# **수행자는 받은 가르침을 스스로 명상에서 질문하고 확인**

합니다.

---

# 제477경 — 아난다도 같은 질문을 한다

현존 제477경은 한 줄입니다.

# **앞의 비구 질문경과 같이 아난다가 물은 경도 같다**

고 압축합니다.

짧게 생략된 경을 다른 전승의 문장으로 길게 채우지 않습니다.

# 제478경 — 부처님이 직접 느낌의 전체 구조를 정리한다

### 삼수
### 촉집
### 촉멸
### 애락·찬탄·염착·견주의 길
### 그 반대의 멸의 길
### 맛
### 위험
### 벗어남

입니다.

왜 이렇게 반복할까요?

# **느낌을 단순히 ‘좋다/싫다’로 보는 습관을 바꾸기 위해서**

입니다.

---

# 제479경 — 부처님 자신의 정각과 느낌의 완전한 앎

부처님은 말합니다.

만약 자신이,

# **느낌**
# **느낌의 집**
# **멸**
# **집의 길**
# **멸의 길**
# **맛**
# **위험**
# **벗어남**

을 사실대로 알지 못했다면,

# **세상에서 해탈·출리·정각을 얻었다고 선언할 수 없었을 것**

이라고 합니다.

사실대로 알았기 때문에 정각을 얻었다고 설명합니다.

---

# 제480경 — 수행자라는 이름보다 느낌을 사실대로 아는가가 기준이다

사문·바라문이라 불려도,

# **느낌의 전체 구조를 사실대로 알지 못하면**
# **수행의 목적을 완성했다고 할 수 없습니다.**

반대로 사실대로 알면,

> **“생은 다했고 범행은 섰으며 할 일을 마쳤다.”**

고 현법에서 스스로 증득할 수 있다고 합니다.

---

# 제475~480경 전체 요약

느낌을 안다는 것은,

# **“지금 기분이 좋다/나쁘다”를 알아차리는 것**

만이 아닙니다.

# **무엇에서 생겼는지**
# **어떻게 꺼지는지**
# **왜 달콤한지**

# **어떻게 벗어나는지**

전체를 압니다.

# 제5경군 — 제481~485경
## 느낌은 얼마나 다양하게 분류될 수 있는가 — 원인·세속/출리·1수에서 108수까지

---

# 제481경 — 느낌은 원인 없이 생기지 않는다

부처님은 반달 동안 홀로 명상한 뒤,
정각 초기부터 관찰했던 내용을 다시 말합니다.

# **모든 중생에게 생기는 느낌은 원인이 있으며 무원인이 아니다.**

### 욕
### 각
### 접촉

을 느낌의 조건으로 말하고,
각 조건의 적멸 여부에 따라 느낌이 생기는 양상을 설명합니다.

또,

### 사견
### 사지
### 사어
### 사업
### 사명
### 사방편
### 사념
### 사정
### 사해탈
### 사지

와

### 정견
### 정지
### 정어
### 정업
### 정명
### 정방편
### 정념
### 정정
### 정해탈
### 정지

---

## [주의] ‘느낌의 원인’을 하나로만 고정하지 않는다

다른 경에서는,

# **촉을 조건으로 느낌이 생긴다**

느낌과 관련된 여러 **연·조건**을 열거합니다.

따라서 서로 모순이라고 성급히 판단하기보다,

# **직접적인 조건과 더 넓은 배경 조건을 구분**

할 필요가 있습니다.

---

# 제482경 — 보시의 복에 머물지 말고 ‘멀리 떠남의 기쁨’을 닦아라

급고독 장자는 석 달 동안,

### 옷
### 음식
### 병든 이의 약

을 부처님과 승가에 공양합니다.

부처님은 그 공덕을 칭찬하면서도,

# **그 복에 만족해 머물지 말라**

고 합니다.

대신,

# **遠離喜樂 — 멀리 떠남의 기쁨과 즐거움**

# **여러 계의 문맥을 구분하고 지·관을 해탈과 연결한 뒤, 느낌을 집중 분석하여 접촉→느낌과 낙·고·불고불락에서 탐·진·치가 자라는 과정을 보고 ‘두 번째 화살’을 만들지 않는 법을 배우는 권**

---

# 제17권에서 꼭 기억할 열 문장

## ① 감각 경험은 계→접촉→인식→욕구→생각→달아오름→추구로 자랄 수 있다
제455경.

## ② `界`는 한 가지 뜻이 아니므로 문맥에 따라 읽어야 한다
제456~463경.

## ③ 지와 관은 서로를 완성하며 함께 해탈로 향한다
제464경.

## ④ 식계도 영원한 참자아가 아니라 비아로 관찰된다
제465경.

## ⑤ 느낌은 접촉을 조건으로 생기고 접촉이 멸하면 함께 멸한다
제466경.

## ⑥ 즐거움에서는 탐, 괴로움에서는 진, 불고불락에서는 치의 잠재적 힘을 경계한다
제468경.

## ⑦ 성스러운 제자도 몸의 통증은 느낀다
제470경.

## ⑧ 수행의 차이는 그 통증에 ‘두 번째 화살’을 더하는가이다
제470경.

## ⑨ “모든 느낌은 고”는 모든 느낌이 실제 통증이라는 뜻이 아니라 모두 무상·변화하기 때문이라는 뜻이다
제473~474경.

## ⑩ 느낌은 1·2·3·4·5·6·18·36·108가지 등 여러 방식으로 나눌 수 있으며 분류보다 목적이 중요하다
제485경.

# [전승·권차 주의]

프로젝트의 권차 지도는 **제17권 = 제455~489경**으로 유지합니다.

다만 현재 프로젝트용 CBETA 통합 검색 원본에서는 제455경이 파일 배열상 `雜阿含經卷第十七`의 권말 표지 뒤에 놓여 있고, 제456~489경이 권17 본문 영역에 먼저 나타나는 **배열상 특이점**이 확인됩니다.

이번 해설에서는 프로젝트의 기존 권차 범위와 연속성을 유지하여 **제455~489경을 모두 제17권 해설 범위에 포함**했습니다.

이 배열 문제를 이용해 원문 내용을 임의 수정하거나 다른 전승으로 보충하지 않았습니다.

# 제17권 최종 정리

『잡아함경』 제17권은 앞의 감각 분석에서 한 걸음 더 들어갑니다.

제455경에서는,

# **계**
→ **접촉**
→ **인식**
→ **욕구**
→ **생각**
→ **달아오름**
→ **추구**

라는 조건 사슬을 다시 확인합니다.

그러나 곧 `界`라는 말의 뜻은 여러 방향으로 펼쳐집니다.

욕계·색계·무색계,
멸계,
출계,
그리고 마음과 견해를 조건 짓는 성향까지 나옵니다.

그래서 이 권은 먼저 중요한 독법을 가르칩니다.

# **같은 불교 용어라도 경마다 문맥을 보고 읽어야 한다.**

제464경에서는 이 다양한 분석이 수행으로 모입니다.

# **지와 관을 함께 닦으라.**

지는 관을 돕고,
관은 지를 돕습니다.

둘은 서로 경쟁하는 수행이 아니라,
갈애와 행을 소멸시키는 해탈의 방향에서 함께 갑니다.

그리고 제465경부터 중심은 **느낌**입니다.

라훌라는,

> **“어떻게 나·내 것·아만을 끊습니까?”**

라고 묻습니다.

부처님은 물질 요소뿐 아니라 **식계까지 비아로 보라**고 합니다.

그 뒤 느낌을 봅니다.

# **접촉이 있으면 느낌이 생기고**
# **접촉이 멸하면 느낌도 멸합니다.**

그러나 느낌 자체가 문제의 전부는 아닙니다.

즐거운 느낌에서는 탐욕,
괴로운 느낌에서는 성냄,
불고불락에서는 어리석음이 자라기 쉽습니다.

이것을 가장 생생하게 보여 주는 것이 제470경의 **두 번째 화살**입니다.

몸이 아픈 것은 첫 번째 화살입니다.

성스러운 제자도 그 화살은 맞습니다.

그러나,

> **“왜 나에게 이런 일이?”**
>
> **“이 고통은 절대 끝나지 않을 것이다.”**
>
> **“모든 것이 망했다.”**

같은 두 번째 마음의 화살을 더 쏘지 않습니다.

따라서 초기불교의 느낌 수행은,

# **아픔을 부정하는 수행도**
# **즐거움을 증오하는 수행도 아닙니다.**

# **느낌을 느낌으로 알고**
# **그 위에 탐·진·치를 더하지 않는 수행**

입니다.

제473~474경은,

> **“그런데 왜 모든 느낌이 괴롭다고 합니까?”**

라는 질문에 정확히 답합니다.

# **모든 행이 무상하고 변하기 때문입니다.**

즐거운 느낌은 실제로 즐겁습니다.

그러나 영원히 붙잡을 수 없습니다.

그래서 제475경은 느낌을,

# **집**
# **멸**
# **맛**
# **위험**
# **벗어남**

으로 모두 봅니다.

맛을 지우지 않고,
위험만 과장하지 않고,
벗어남까지 봅니다.

그리고 제485경은 놀라운 결론을 줍니다.

느낌은 상황에 따라,

# **1개**
# **2개**
# **3개**
# **4개**
# **5개**
# **6개**
# **18개**
# **36개**
# **108개**

로도 말할 수 있습니다.

서로 모순되는 것이 아닙니다.

# **무엇을 분석하려는가에 따라 같은 경험을 여러 방식으로 나눌 수 있기 때문입니다.**

따라서 제17권은 결국 숫자나 명칭보다 더 중요한 것을 말합니다.

# **느낌을 사실대로 아는가.**
# **그 느낌이 어떻게 생기고 사라지는지 아는가.**
# **그 맛과 위험을 함께 보는가.**
# **그리고 두 번째 화살을 더하지 않고 놓을 수 있는가.**

그것이 느낌에서 해탈로 가는 길입니다.

---

# 제17권을 한 문장으로

# **『잡아함경』 제17권은 여러 계가 접촉·인식·욕구·추구를 조건 짓는 구조와 지·관의 병행을 설명한 뒤, 느낌이 접촉에서 생기며 즐거움·괴로움·불고불락에서 탐·진·치가 자랄 수 있음을 밝히고, 느낌의 집·멸·맛·위험·벗어남을 사실대로 알아 신체의 첫 번째 화살 위에 마음의 두 번째 화살을 더하지 않는 해탈의 길을 가르친다.**
