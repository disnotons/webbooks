# 『잡아함경 쉬운 완전읽기』 제22권
## 천상의 즐거움도 무상하다 — 천신 문답·세속가명·연기·급고독 장자의 귀의·신뢰와 불방일

> **범위:** 『잡아함경』 제22권, 제576경~제603경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』 卷第二十二  
> **수록 경수:** **28경**  
> **읽기 방식:** 제22권은 대부분 짧은 **천신 게송 문답**으로 이루어져 있다. 그러나 주제는 단순한 천상 찬탄이 아니다. 오히려 **천상의 즐거움보다 무상과 적멸을 앞세우고, 아라한이 일상어로 ‘나’를 말해도 아만에 집착하지 않는다는 세속가명, 정법·참괴·정념·감각수호·지혜·불방일**을 반복해서 강조한다. 중간의 제590~595경에서는 재가 수행자와 급고독 장자의 이야기가 길게 이어지며 **연기 관찰·귀의·보시·계·지혜·재생 전승**을 보여 준다. 권말 제603경은 이 모든 흐름을 **신뢰·불방일·정진·지혜** 네 항목으로 압축한다.

---

# 한 문장 핵심

『잡아함경』 제22권은 이렇게 정리할 수 있습니다.

# **천상·재산·가족·명예 같은 좋은 조건도 영원한 안식처는 아니며, 모든 행은 무상하고 생멸하는 법이다. 수행자는 ‘나’라는 말을 없애는 사람이 아니라 그 말에 실체적 아만을 붙이지 않는 사람이고, 정법·참괴·정념·감각수호·연기 관찰·신뢰·불방일·정진·지혜를 통해 탐욕과 생사의 흐름을 끊는다.**

이번 권의 큰 흐름은 다음과 같습니다.

# **천상의 즐거움**
→ **무상·생멸**
→ **적멸이 더 큰 안락**

언어에서는,

# **“나”라고 말함**
≠ **아만에 집착함**

수행에서는,

# **정법**
# **참괴**
# **정념**
# **감각수호**
# **연기 관찰**
# **불방일**
# **정진**
# **지혜**

가 반복됩니다.

# 제1경군 — 제576~589경
## 천신과의 게송 문답 — 무상·자비·참괴·세속가명·가족의 결박·정념

---

# 제576경 — 난다원보다 더 큰 즐거움은 무엇인가

한 천신이 말합니다.

> **“난다원에 있지 않으면 진정한 즐거움을 얻지 못한다.”**

난다원은 삼십삼천의 즐거운 동산입니다.

부처님은 답합니다.

# **「一切行無常，是則生滅法；生者既復滅，俱寂滅為樂。」**

쉽게 풀면,

# **모든 행은 무상하고**
# **생겼다가 멸하는 법이며**
# **그 생멸의 완전한 고요가 안락하다**

는 뜻입니다.

---

## 천상의 즐거움도 최종 기준이 아니다

제576경은 제21권 마지막 질다 장자의 태도와 잘 연결됩니다.

질다 장자는 전륜왕의 권력도 무상하다고 했습니다.

이번에는 천신이,

# **천상의 쾌락이 최고의 행복**

이라고 생각하지만,
부처님은 **적멸**을 더 앞에 둡니다.

[주의]

# **“즐거움은 전부 나쁘다”**

는 뜻이 아닙니다.

초기불교는 즐거움의 존재를 인정하지만,
그것을 **영원히 붙잡을 수 있는 최종 안식처**로 보지 않습니다.

---

# 제577경 — 해탈했는데 왜 다른 중생을 가르치는가

천신은 묻습니다.

> **“모든 결박을 끊은 무니라면 집도 없는데, 왜 사문은 사람들을 가르칩니까?”**

부처님은 답합니다.

# **모든 중생은 서로 얽혀 있고**
# **지혜로운 사람이 어찌 그들을 불쌍히 여기지 않겠는가**

라고 합니다.

여래가 중생을 가르치는 것은,

# **자비와 연민**

때문입니다.

---

## 해탈 = 세상 사람에게 무관심?

제577경은 그렇게 말하지 않습니다.

# **자신의 결박에서 벗어남**
과
# **다른 존재에 대한 연민**

은 양립할 수 있습니다.

해탈은 냉담함과 같은 말이 아닙니다.

---

# 제578경 — 부끄러움과 도덕적 거리낌

천신은,

# **늘 참괴의 마음을 익히는 사람은 악에서 멀어진다**

고 말합니다.

부처님도 이를 승인합니다.

[비유]

# **좋은 말이 채찍을 보기만 해도 방향을 고치는 것**

에 비유합니다.

여기서 `慚愧`는 단순한 자기혐오가 아닙니다.

# **잘못을 부끄러워하고**
# **해로운 행동을 꺼리는 윤리적 감각**

입니다.

[주의]

# **“나는 나쁜 인간이다”라는 수치심**

으로 바꾸지 않습니다.

초점은 **행동을 악에서 돌리는 기능**입니다.

---

# 제579경 — 정법을 가까이하지 않으면 오래 잠든 것과 같다

천신은,

# **정법을 가까이하지 않고**
# **그릇된 견해를 즐기며**
# **잠들어 깨어나지 못하는 사람**

을 노래합니다.

부처님은,

# **정법을 전념해 닦고**
# **불선업에서 멀어진 누진 아라한**

을 답으로 제시합니다.

---

# 제580경 — 법으로 조복되면 다른 견해에 휩쓸리지 않는다

천신은,

# **법으로 잘 조복되고 여러 견해를 따라가지 않는 사람**

을 말합니다.

부처님은 이를 이어,

# **무지가 끝나고 세속적 애착을 건너는 방향**

을 말합니다.

제579~580경은,

# **정법을 배우고**
# **그 법으로 마음을 조복해**
# **견해의 유행에 끌려다니지 않는 것**

을 강조합니다.

---

# 제581경 — 아라한이 “나”라고 말해도 되는가

천신이 매우 중요한 질문을 합니다.

> **“누가 다한 아라한이 ‘내가’라고 말하고 ‘내 것’이라고 말할 수 있습니까?”**

부처님의 답은 뜻밖입니다.

# **그렇게 말해도 허물이 없다.**

그러자 천신이 다시 묻습니다.

> **“그렇다면 아라한도 아만에 의지해 ‘나’라고 말합니까?”**

부처님은 분명히 부정합니다.

# **아만에서 이미 떠났고**
# **‘나·내 것’에 마음이 붙지 않으며**
# **세상의 이름을 잘 이해하여**
# **평등한 가명으로 말할 뿐이다.**

---

## 세속가명 — 일상어를 쓰는 것과 자아 집착은 다르다

제581경은 무아를 이해하는 데 아주 중요합니다.

아라한도,

> **“내가 갑니다.”**
>
> **“내 옷입니다.”**

같은 일상어를 사용할 수 있습니다.

하지만,

# **그 말 때문에 영원한 실체적 자아를 믿는 것은 아닙니다.**

경의 표현은,

# **善解世名字，平等假名說**
# **세상의 명칭을 잘 이해해 가명으로 말한다**

입니다.

[주의]

# **무아 수행 = ‘나’라는 단어를 사용하지 않는 훈련**

이 아닙니다.

---

# 제582경 — “나”라고 말하지만 ‘나’에 붙지 않는다

제582경은 같은 내용을 다시 반복합니다.

아라한이,

# **“나의 누가 다했다”**

라고 말할 수 있지만,

# **‘내 것’에 집착하지 않습니다.**

다시,

# **세상의 이름을 잘 이해해 가명으로 말한다**

고 합니다.

제581~582경은,

# **언어적 1인칭**
과
# **아만·자아집착**

을 명확히 구분합니다.

---

# 제583경 — 라후가 달을 가린다는 전승

현존 경문에서는,

# **라후 아수라왕이 달의 천자를 가립니다.**

달의 천자들은 두려워 부처님께 귀의하고,
부처님은 게송을 말해 라후에게 달을 놓으라고 합니다.

라후는 두려워 달을 놓습니다.

[전승]

이것은 고대 인도의 **일식·월식과 연결된 라후 신화·천문 전승** 안에 있는 이야기입니다.

이를 원문에서 지우지 않습니다.

하지만,

# **현대 천문학에서 월식이 실제 아수라 때문에 일어난다는 설명**

으로 제시하지 않습니다.

제583경의 종교적 핵심은,

# **두려움 속에서 부처에게 귀의하는 천신들과 부처의 보호자적 역할**

이라는 전승입니다.

---

# 제584경 — 가족과 애욕의 결박

천신은,

### 족본
### 다시 생기는 족속
### 서로 이어지는 관계
### 단단한 결박

이 무엇인지 묻습니다.

부처님은 게송에서,

### 어머니를 세상의 족본
### 아내를 다시 생기는 족속
### 자식을 서로 이어지는 관계
### 애욕을 단단한 결박

으로 표현합니다.

자신은 그 결박에서 벗어났다고 합니다.

---

## [주의] 가족이 악이라는 뜻인가

제584경을,

# **“어머니·배우자·자녀는 나쁘다.”**

라고 읽지 않습니다.

출가 수행의 문맥에서,

# **가족관계에 대한 애욕과 집착이 존재의 결박으로 작동할 수 있음**

을 게송으로 표현한 것입니다.

초기불교에는 재가자의 부모·가족 책임을 긍정하는 가르침도 있습니다.

---

# 제585경 — 근심도 환희도 마음을 흔들지 못한다

한 천신이 홀로 앉아 있는 부처님께 묻습니다.

> **“슬픕니까?”**
>
> **“기쁩니까?”**

부처님은,

# **근심에 시달리지도 않고**
# **환희에 들뜨지도 않는 상태**

를 말합니다.

천신이 이유를 묻자,
부처님은,

# **번뇌에서 환희가 생기고**
# **그 환희에서도 다시 번뇌가 생길 수 있다**

는 게송을 말합니다.

---

## [주의] 기쁨은 나쁘다는 뜻인가

초기경전은 선정의 희·락을 긍정적으로도 말합니다.

따라서 제585경의 `歡喜`를 **모든 건전한 기쁨**으로 확대하지 않습니다.

여기서는,

# **번뇌를 먹고 자라는 들뜬 기쁨과 근심 모두에 휘둘리지 않는 고요**

가 중심입니다.

---

# 제586경 — 머리에 불이 붙은 것처럼 무엇을 급히 끊을 것인가

천신은,

# **예리한 칼이 해치고 머리에 불이 붙은 것처럼**
# **탐욕의 불을 급히 끊으라**

고 말합니다.

부처님은 한 걸음 더 나아갑니다.

# **후유(後有), 즉 뒤의 존재가 이어지는 조건을 끊기 위해**
# **정념으로 이욕을 구하라**

고 합니다.

[주의]

실제 화재나 신체 위험을 무시하라는 생활 지침이 아닙니다.

# **생사의 조건을 끊는 수행의 긴급성**

을 비유합니다.

---

# 제587경 — 생사의 숲을 빠져나가는 수레

천신은 천녀들에 둘러싸인 삶을,

# **어리석음의 숲**

에 비유하고 빠져나갈 길을 묻습니다.

부처님은 수행을 **수레**에 비유합니다.

### 곧고 평등한 길
### 두려움에서 벗어난 방향
### 고요의 수레
### 법이라는 덮개
### 참괴라는 끈
### 정념이라는 고삐
### 지혜로운 마부
### 정견이라는 앞잡이

입니다.

이 수레는,

# **남녀 누구나 탈 수 있고**
# **생사의 숲에서 벗어나 안락한 곳에 이른다**

고 합니다.

---

## 제587경의 특징

# **성별보다 수행 조건이 중요합니다.**

게송은 이 수레를,

# **남자와 여자 모두의 것**

이라고 명시합니다.

---

# 제588경 — ‘네 번 돌고 아홉 문’의 코끼리 비유

천신은,

> **“네 번 돌고 아홉 문이 있으며 탐욕으로 가득하고 진흙에 깊이 빠진 큰 코끼리가 어떻게 빠져나옵니까?”**

라고 묻습니다.

부처님은,

# **애착과 기쁨의 긴 끈을 끊고**
# **탐욕 등의 악을 끊으며**
# **애욕의 뿌리를 뽑아**
# **바르게 그곳을 향하라**

고 답합니다.

[주의 — 원문 난해]

`四轉九門`이 정확히 무엇을 지시하는지는
현존 제588경의 짧은 게송만으로 입문 해설에서 단정하지 않습니다.

후대 주석이나 평행전승의 해석을
현존 한역 자체의 뜻인 것처럼 끼워 넣지 않습니다.

확실한 것은,

# **애욕의 뿌리와 탐욕의 결박을 끊는 것**

이 탈출의 핵심이라는 점입니다.

---

# 제589경 — 끝없는 재산 경쟁은 어떻게 쉬는가

천신은 상인들이,

# **이미 부유하면서도 서로 더 큰 부를 경쟁하고**
# **재산을 얻기 위해 불처럼 치열하게 달리며**
# **욕탐이 계속 질주하는 모습**

을 묘사합니다.

부처님은 출가 수행의 관점에서,

# **가족과 재산에 대한 집착을 내려놓고**
# **탐·진·치에서 이욕하여**
# **누가 다하고**
# **갈애가 다하면**
# **그 끝없는 추구도 쉰다**

고 답합니다.

[주의]

# **재산을 가진 것 자체가 악**

이라는 뜻이 아닙니다.

제504경에서 보시는 재산을 선하게 사용하는 행위로 칭찬되었습니다.

제589경의 문제는,

# **경쟁적 욕탐이 멈추지 않는 상태**

입니다.

---

# 제576~589경 전체 요약

천신 문답은 매우 짧지만,
반복되는 기준은 분명합니다.

# **천상보다 적멸**
# **무관심보다 자비**
# **자기혐오보다 참괴**
# **견해 유행보다 정법**
# **‘나’라는 말 금지보다 아만의 소멸**
# **가족·재산 자체의 악마화보다 애욕의 결박**
# **정념·정견·지혜**

입니다.

# 제2경군 — 제590~591경
## 재가 수행은 말이 아니라 삶에서 검증된다 — 연기 관찰과 욕망 비판의 위선

---

# 제590경 — 밤에 연기를 관찰한 재가 수다원

과거 꼬살라의 상인 500대 수레가 황야를 지나가고,
500명의 도적이 뒤따라 기회를 노립니다.

길가의 한 천신은 생각합니다.

> **“상인들에게 법의 뜻을 물어 보자. 잘 답한다면 도적에게서 보호해 주겠다.”**

천신은 게송으로 묻습니다.

> **“누가 깨어 있으면서 잠들고, 누가 잠들어 있으면서 깨어 있는가?”**

---

## 상인 가운데 한 우바새

상인들 가운데 한 재가자가 있습니다.

그는,

# **불·법·승을 믿고**
# **삼보에 귀의하며**
# **불·법·승과 사성제에 의심이 없고**
# **첫 번째 무간등의 과를 얻은 사람**

이라고 설명됩니다.

그는 후야에 앉아,

# **십이연기를 순관과 역관으로 관찰**

합니다.

# **이것이 있으므로 저것이 있고**
# **이것이 일어나므로 저것이 일어난다**

에서,

# **무명 → 행 → 식 → 명색 → 육입처 → 촉 → 수 → 애 → 취 → 유 → 생 → 노사우비뇌고**

를 보고,

반대로,

# **무명멸 → … → 노사우비뇌고멸**

을 봅니다.

---

## ‘깨어 있음’의 의미

우바새는 천신에게 답합니다.

아라한은,

# **탐·진·치가 다하고**
# **누가 다하고**
# **바른 지혜로 마음이 해탈했으므로 깨어 있는 사람**

입니다.

반대로,

# **괴로움**
# **괴로움의 원인**
# **소멸**
# **소멸로 가는 길**

을 모르는 사람은,
겉으로 눈을 뜨고 있어도 **잠든 사람**과 같습니다.

---

## 천신이 상인들을 보호한다는 전승

천신은 우바새의 답을 칭찬하고,
그 덕분에 상인들이 도적에게서 안전하게 황야를 벗어났다고 전합니다.

[전승]

천신의 보호는 현존 경전의 전승 요소입니다.

이를 현대의 여행 안전 보장으로 설명하지 않습니다.

---

## 제590경의 중요한 점

# **재가자도 연기를 깊이 관찰합니다.**

제21권의 질다 장자에 이어,
재가 수행이 단순히 보시와 계에서 끝나지 않는다는 점을 보여 줍니다.

---

# 제591경 — 남에게 욕망을 비판하고 집에 와서는 탐닉한다면

한 우바새가 다른 재가자들의 모임에서,

# **욕망은 허망하고 속이며 아이를 속이는 환술과 같다**

고 강하게 비판합니다.

그런데 자기 집으로 돌아오자,

# **자신은 오욕을 마음껏 즐깁니다.**

그 집의 천신은 이를 보고 모순을 지적합니다.

> **“남들 앞에서는 욕망이 무상하고 허망하다고 하면서, 왜 자신은 욕망에 빠져 있는가?”**

---

## 말과 삶이 일치해야 한다

천신의 지적을 들은 우바새는 깨어나,

# **머리와 수염을 깎고**
# **출가해**
# **부지런히 수행하여**
# **아라한이 되었다**

고 전합니다.

제591경의 핵심은,

# **욕망에 대한 이론적 비판**
보다
# **자신의 실제 삶이 그 말과 일치하는가**

입니다.

[주의]

재가생활이나 배우자·자녀 자체를 비난하는 경으로 만들지 않습니다.

경이 직접 지적하는 것은,

# **남에게는 엄격한 법을 말하면서 자신은 정반대로 행동하는 위선**

입니다.

---

# 제590~591경 전체 요약

# **연기를 직접 관찰하는 재가자**
와
# **법을 말하면서 자기 삶에서는 반대로 사는 재가자**

가 대비됩니다.

초기불교에서 중요한 것은,

# **말의 수준**
이 아니라
# **실제 앎과 실제 삶**

입니다.

# 제3경군 — 제592~595경
## 급고독 장자의 첫 만남과 재가 제자들의 천상 전승

---

# 제592경 — 급고독 장자가 처음 ‘부처’라는 말을 듣다

급고독 장자 수닷따는 왕사성에 머물던 중,
한 장자의 집이 밤새 분주한 것을 봅니다.

> **“결혼식인가? 왕이나 대신을 초대한 것인가?”**

라고 묻습니다.

장자는 답합니다.

# **“부처님과 비구승가를 공양하려고 준비하는 것입니다.”**

급고독 장자는,

# **‘부처’라는 이름을 처음 듣고도 크게 기뻐합니다.**

몸의 털이 설 정도로 환희가 일어납니다.

---

# 부처님을 보러 가는 길

급고독 장자는 그날 밤,

# **부처님을 생각하다 잠듭니다.**

새벽이라고 착각해 성문 밖으로 나가지만,
아직 어두운 밤입니다.

두려워 돌아가려 할 때
성문 곁의 천신이 빛을 내며,

# **“앞으로 가십시오. 돌아가지 마십시오. 큰 이익을 얻을 것입니다.”**

라고 권합니다.

천신은,

# **수많은 말·황금·수레·보석·코끼리·미녀를 보시하는 것보다**
# **부처를 향해 한 걸음 가는 공덕이 더 크다**

는 강렬한 게송을 말합니다.

[전승]

천신의 개입과 공덕의 비교는 전승적 표현입니다.

이를 수학적 공덕 계산식으로 바꾸지 않습니다.

---

# 부처님과의 첫 만남

급고독 장자는 한림의 묘지 사이에서 경행 중인 부처님을 만납니다.

그는 세속의 예법으로,

> **“편안히 주무셨습니까?”**

라고 묻습니다.

부처님은 게송으로,

# **애욕에 물들지 않고**
# **희망과 번뇌를 끊으며**
# **마음이 고요해진 사람이 편안히 잔다**

고 답합니다.

---

# 부처님의 단계적 설법

현존 제592경은 부처님이 급고독 장자에게,

# **보시의 복**
# **지계의 복**
# **천상에 태어나는 복**
# **욕망의 맛**
# **욕망의 위험**
# **욕망에서 벗어남**
# **멀리 떠남의 복**

을 설했다고 기록합니다.

장자는,

# **법을 듣고**
# **법을 보고**
# **법을 얻고**
# **법에 들어가**
# **법을 이해하고**
# **의심을 건너**
# **남의 믿음에만 의지하지 않게 됩니다.**

그리고 평생,

# **불·법·승에 귀의한 우바새**

가 되겠다고 선언합니다.

---

## 기원정사의 출발

급고독 장자는 자신이 사는 사위성에는 정사가 없다고 말합니다.

부처님은,

# **비구들이 오갈 수 있는 정사를 세울 수 있다**

고 합니다.

급고독 장자는 부처님이 사위국에 와 준다면,

# **정사와 승방을 지어 공양하겠다**

고 청합니다.

부처님은 침묵으로 이를 받아들입니다.

제592경은 훗날 **기원정사**와 연결되는 급고독 장자 후원의 출발 장면입니다.

---

# 제593경 — 급고독 장자가 죽은 뒤 도솔천에 태어났다는 전승

현존 한역은 급고독 장자가 병으로 죽은 뒤,

# **도솔천에 태어났다**

고 전합니다.

천자가 된 그는 부처님께 와서 게송을 말합니다.

그 게송의 핵심은,

# **깊은 신뢰**
# **깨끗한 계**
# **업**
# **지혜**

가 사람을 청정하게 하는 것이지,

# **출생 신분이나 재산이 사람을 청정하게 하는 것이 아니다**

라는 것입니다.

---

## 사리불에 대한 존경

급고독 천자는 특히,

# **사리불의 큰 지혜·정념·고요·멀리 떠남**

을 찬탄합니다.

아난다는 그 천자가 급고독 장자였을 것이라고 추정하고,
부처님은 이를 확인합니다.

현존 경문은 이어 사리불의 지혜를 매우 높게 찬탄합니다.

[전승]

도솔천 재생은 현존 한역의 재생 전승입니다.

이를 믿음의 의무로 강요하지 않습니다.

---

# 제594경 — “부처를 보고, 법을 듣고, 승가를 공양하는 데 만족하지 않았다”

광야 장자가 죽어,

# **무열천(無熱天)**

에 태어났다고 전합니다.

천신의 몸이 너무 미세해 땅에 서지 못하자,
부처님이 거친 몸으로 변화하라고 합니다.

부처님은 묻습니다.

> **“인간일 때 배운 법을 아직 기억합니까?”**

천자는,

# **기억할 뿐 아니라 당시 다 배우지 못했던 법까지 지금 기억한다**

고 답합니다.

---

## 세 가지에 만족하지 않았다

부처님이 묻습니다.

> **“인간일 때 어떤 세 가지에 만족하지 않았기에 그곳에 태어났습니까?”**

천자는 답합니다.

# **부처님을 보는 데 만족하지 않았고**
# **법을 듣는 데 만족하지 않았으며**
# **승가를 공양하는 데 만족하지 않았습니다.**

게송은,

# **성스러운 법을 받아 지니고**
# **인색함과 집착의 때를 조복한 것**

도 함께 찬탄합니다.

[주의]

여기의 “만족하지 않음”은 탐욕적 욕심이 아닙니다.

# **선한 법을 더 배우고 실천하고자 하는 의욕**

입니다.

제561경의 **갈애와 선한 의욕의 구분**과 연결됩니다.

---

# 제595경 — 무번천의 일곱 해탈한 비구와 난디팔라 도공

무번천의 한 천자가 부처님께 와서,

# **그곳에 태어난 일곱 비구가 탐욕과 성냄을 다하고 세속의 애착을 건넜다**

고 말합니다.

부처님은 그들의 이름을 듭니다.

그리고 그 천자가 누구인지 묻습니다.

천자는 자신이,

# **난디팔라**
# **가섭불의 재가 제자**
# **도공**
# **부모를 봉양하고**
# **욕망에서 떠나 범행을 닦았던 사람**

이라고 밝힙니다.

---

## 오래된 선한 벗의 전승

천자는 부처님과 자신이 과거부터 서로 좋은 벗이었다고 말합니다.

현존 경문은,

# **선한 인연과 수행이 여러 생에 걸쳐 이어진다는 전승**

을 보여 줍니다.

[전승]

과거불·숙명·천상 재생은 초기불교의 전승 요소입니다.

삭제하지 않되,
현대 역사학적으로 확인된 사실이라고 말하지 않습니다.

### 삼보에 귀의

### 범행

# 제4경군 — 제596~603경
## 해탈을 향한 압축 게송 — 계·지혜·정진·감각수호·불방일

# 제596경 — 두려움에서 벗어날 길

천신은,

# **세상은 두려움이 많고**
# **중생은 늘 괴로움에 흔들리며**
# **이미 일어난 괴로움도 있고 앞으로 일어날 괴로움도 있다**

고 말합니다.

그리고,

> **“두려움에서 벗어나는 곳이 있습니까?”**

라고 묻습니다.

부처님의 한역 게송은 매우 압축적입니다.

# **고행**
# **감각기관의 조복**
# **모든 것을 놓아 버림**
# **해탈**

을 한 문장에 연결합니다.

[주의 — 원문 압축]

평행전승 후보로 SN 2.17이 있지만,
이번 해설에서는 한역이 직접 보여 주는 범위 안에서,

# **해탈은 감각수호와 놓아 버림을 포함하는 실제 훈련과 연결된다**

는 점만 안전하게 잡습니다.

# 제597경 — 누가 천신의 공양을 받을 만한가

천신이 묻습니다.

### 어떻게 아름다운 몸을 얻는가
### 어떻게 출리의 길을 타는가
### 어떤 법에 머무는가
### 무엇을 닦는가
### 천신들은 누구를 공양하는가

부처님은 답합니다.

# **계를 지키고**
# **밝은 지혜가 있으며**
# **바른 삼매를 닦고**
# **마음을 곧게 하며 정념을 세우고**
# **근심을 없애며**
# **평등한 지혜를 얻고**
# **마음이 잘 해탈한 사람**

이라고 합니다.

# **계·삼매·정념·지혜·해탈**

이 함께 묶여 있습니다.

---

# 제598경 — 졸림·과식·게으름이 성도를 가린다

천신은,

### 잠에 가라앉음
### 하품과 무기력
### 즐거워하지 못함
### 과식
### 마음의 혼란
### 게으름
### 정진하지 않음

등이 중생을 덮어,

# **성도가 드러나지 않게 한다**

고 말합니다.

부처님은,

# **정진해 닦는 사람이 성도를 열어 드러낸다**

고 답합니다.

[주의]

# **잠을 자면 안 된다**

는 뜻이 아닙니다.

제503경은 중야의 수면을 인정했습니다.

문제는,

# **졸림·과식·무기력·게으름에 계속 끌려 수행을 놓치는 상태**

입니다.

---

# 제599경 — 복잡하게 얽힌 마음을 누가 푸는가

천신은,

> **“바깥 얽힘과 안의 얽힘 속에서 누가 결박을 풀 수 있습니까?”**

라고 묻습니다.

부처님은,

# **지혜로운 사람이 계를 세우고**
# **안으로 지혜를 닦으며**
# **부지런히 수행하면**
# **얽힘을 풀 수 있다**

고 합니다.

제597경과 마찬가지로,

# **계 + 지혜 + 정진**

이 함께 갑니다.

---

# 제600경 — 거북이가 몸을 껍질 속에 거두듯

천신은 수행자의 마음이 생각을 따라 자꾸 가라앉는다고 묻습니다.

부처님은 비유합니다.

[비유]

# **거북이가 여섯 지체를 껍질 안에 거두는 것처럼**
# **비구는 선정과 사유를 닦아 여러 생각과 표상을 잘 거둔다.**

그 마음은,

# **어디에도 기대어 붙지 않고**
# **타인이 쉽게 두렵게 만들지 못하며**
# **비난할 틈을 주지 않습니다.**

---

## [주의] 거북이의 ‘여섯’을 곧바로 여섯 감각문이라고 단정할까

이 비유는 여섯 감각문을 거두는 수행을 자연스럽게 떠올리게 합니다.

그러나 현존 한역 게송은 직접,

# **善攝諸覺想 — 여러 생각과 표상을 잘 거둔다**

고 말합니다.

따라서 입문 해설에서는,

# **감각·생각의 문을 함부로 따라가지 않고 마음을 거두는 비유**

정도로 설명하는 것이 안전합니다.

---

# 제601경 — 생사의 길은 어디에서 돌아서나

천신이 묻습니다.

> **“어디에서 흐름이 되돌아가며, 어디에서 생사의 길이 더 돌지 않고, 어디에서 세상의 고락이 남김없이 멸합니까?”**

부처님은,

# **눈·귀·코·혀·몸·마음**
과
# **명색**

이 남김없이 멸하는 곳에서,

# **흐름이 되돌아가고**
# **생사의 길이 더 돌지 않으며**
# **고락이 남김없이 멸한다**

고 답합니다.

[주의]

이를,

# **감각기관을 물리적으로 파괴해야 한다**

는 뜻으로 읽지 않습니다.

앞 경들에서 여섯 감각처와 명색은 연기의 조건 구조 안에서 다뤄졌습니다.

# **조건 지어진 경험과 취착의 흐름이 멸하는 것**

이 문맥입니다.

---

# 제602경 — 다섯 감각 욕망과 마음의 법에서 욕탐이 없으면

천신은,

> **“어떻게 괴로움에서 벗어납니까?”**

라고 묻습니다.

부처님은,

# **세간의 다섯 욕망**
과
# **마음의 법을 여섯째**

로 들고,

# **그것들에 욕탐이 없으면**
# **모든 괴로움에서 해탈한다**

고 답합니다.

다시 중요한 구분이 나옵니다.

# **대상 자체의 소멸**
보다
# **그 대상에 대한 욕탐의 소멸**

이 핵심입니다.

제572경의,

# **눈과 색이 묶는 것이 아니라 욕탐이 묶는다**

는 가르침과 연결됩니다.

# 제603경 — 신뢰·불방일·정진·지혜

제22권 마지막 경은 네 문장으로 매우 압축되어 있습니다.

천신이 묻습니다.

> **어떻게 여러 흐름을 건넙니까?**
>
> **어떻게 큰 바다를 건넙니까?**
>
> **어떻게 괴로움을 버립니까?**
>
> **어떻게 청정해집니까?**

부처님은 답합니다.

# **信能度諸流**
# **신뢰가 여러 흐름을 건너게 한다.**

# **不放逸度海**
# **불방일이 큰 바다를 건너게 한다.**

# **精進能除苦**
# **정진이 괴로움을 덜어 낸다.**

# **智慧得清淨**
# **지혜로 청정해진다.**

# 제1~22권의 흐름

## 제1권
오온을 왜 나·내 것으로 붙잡을 수 없는가

## 제2권
왜 그래도 계속 오온을 나라고 붙잡는가

## 제3권
자기화는 어떤 조건으로 생기고 사라지는가

## 제4권
그 가르침을 이해한 사람은 세상 속에서 어떻게 살아야 하는가

## 제5권
무아 이해 뒤에도 남는 미세한 ‘나는’과 해탈의 오해

## 제6권
수행의 목적과 괴로움의 흐름을 어떻게 끝내는가

## 제7권
자아견에서 여러 철학적 견해가 어떻게 생기고 수행 전체로 어떻게 끊는가

## 제8권
감각 경험에서 접촉·느낌·갈애·취착이 어떻게 생기는가

## 제9권
감각기관과 대상 자체가 아니라 욕탐이 결박임을 알고 감각문을 지키는 법

## 제10권
무명이 무엇인지 밝히고 연기의 중도와 밝은 앎을 닦는 법

## 제11권
보고 듣되 좋아함과 싫어함에 끌려가지 않는 감각수호

## 제12권
괴로움의 조건 사슬 전체와 유·무 두 극단을 떠난 연기의 중도

## 제13권
육육법으로 감각 경험을 해부하고 ‘사람·나’라는 명칭·업·공·평형까지 연결

## 제14권
연기의 앎을 정견·법주지·혜해탈·44지·77지로 정밀화

## 제15권
네 가지 음식과 사성제를 통해 괴로움의 공급·진단·소멸·길을 통합

## 제16권
주의력·동류 성향·18계와 접촉→느낌→갈애→추구의 조건을 살핌

## 제17권
느낌을 집중 분석해 두 번째 화살과 맛·위험·벗어남을 배움

## 제18권
팔정도·계율·갈등 해결·확신·정명·삼매·정진으로 수행 생활 전체를 점검

## 제19권
업·재생 과보 서사를 읽되 피해자 비난을 피하고 사념처라는 현재 수행으로 돌아옴

## 제20권
사념처를 해탈까지 확장하고 갈등·신분·육념·감각의 흐름·무상심삼매를 살핌

## 제21권
선한 의욕을 사용하고 놓는 구조, 네 청정, 질다 장자의 삼매·신견·욕탐의 결박을 살핌

## 제22권
# **천신과 재가자 전승 속에서 천상의 즐거움도 무상함을 확인하고, 아라한의 ‘나’라는 말과 아만을 구분하며, 재가자의 연기 관찰·급고독 장자의 귀의·선한 의욕·감각수호를 거쳐 신뢰·불방일·정진·지혜로 청정에 이르는 길을 압축하는 권**

---

# 제22권에서 꼭 기억할 열두 문장

## ① 천상의 즐거움도 모든 행의 무상·생멸을 벗어나지 않는다
제576경.

## ② 해탈한 사람의 가르침은 중생에 대한 자비와 연민에서 나온다
제577경.

## ③ 참괴는 자기혐오가 아니라 악행에서 물러나는 윤리적 감각이다
제578경.

## ④ 아라한도 일상어로 “나·내 것”을 말할 수 있다
제581~582경.

## ⑤ 중요한 것은 ‘나’라는 단어를 지우는 것이 아니라 아만과 집착에서 벗어나는 것이다
제581~582경.

## ⑥ 제583경의 라후·월천자 이야기는 고대 천문·신화 전승이며 현대 월식 설명으로 읽지 않는다

## ⑦ 가족과 재산 자체보다 애욕과 경쟁적 탐욕이 결박이 될 수 있다
제584·589경.

## ⑧ 재가 수다원도 후야에 십이연기를 순·역으로 관찰한다
제590경.

## ⑨ 남에게 욕망을 비판하면서 자신은 탐닉한다면 법 이해가 삶에 내려오지 않은 것이다
제591경.

## ⑩ 급고독 장자의 신뢰는 법을 듣고 의심을 건너는 이해와 귀의로 깊어진다
제592경.

## ⑪ 감각 대상 그 자체보다 그것에 대한 욕탐이 해탈의 핵심 문제다
제602경.

## ⑫ 신뢰로 흐름을 건너고, 불방일로 바다를 건너며, 정진으로 괴로움을 덜고, 지혜로 청정해진다
제603경.

| 제597경 | 계·지혜·삼매·정념·평등한 지혜·마음해탈을 갖춘 사람을 천신들이 공양한다는 게송 |
| 제598경 | 졸림·하품·과식·혼란·게으름이 성도를 가리며 정진이 길을 연다고 함 |

| 제602경 | 다섯 감각 욕망과 마음의 법에서 욕탐이 없으면 모든 괴로움에서 해탈 |
| 제603경 | 신뢰로 흐름을 건너고, 불방일로 바다를 건너며, 정진으로 괴로움을 제거하고, 지혜로 청정해짐 |

# [주의] 제22권에서 생기기 쉬운 대표 오해

## “천상은 가장 좋은 최종 목표다”

제576경부터 그렇지 않습니다.

# **천상 쾌락보다 무상·생멸·적멸을 더 높은 기준**

으로 둡니다.

---

## “무아를 깨달으면 ‘나’라는 단어를 쓰면 안 된다”

제581~582경이 직접 반박합니다.

# **아라한도 세속의 가명으로 ‘나’를 말할 수 있습니다.**

문제는 아만과 집착입니다.

---

## “월식은 라후 아수라가 달을 삼켜서 생긴다”

제583경의 고대 전승을 현대 천문학 설명으로 사용하지 않습니다.

---

## “가족이 곧 결박이므로 가족을 사랑하면 수행할 수 없다”

제584경은 출가 수행자의 애욕 결박을 게송으로 말합니다.

# **가족 책임과 자비 전체를 부정하는 경으로 확대하지 않습니다.**

---

## “재산이 있으면 해탈할 수 없다”

제589경은 재산의 존재보다,

# **끝없이 더 많이 가지려는 경쟁적 욕탐**

을 문제로 삼습니다.

급고독 장자처럼 재산을 보시와 승가 후원에 쓰는 재가자도 중요한 제자로 등장합니다.

---

## “신뢰만 있으면 지혜나 수행은 필요 없다”

제603경은 네 요소를 함께 둡니다.

# **신뢰 + 불방일 + 정진 + 지혜**

입니다.

제590·592경에서도 신뢰는 **연기 관찰과 직접 법 이해**로 깊어집니다.

---

## “졸리면 수행 자격이 없다”

제598경의 문제는 일시적인 피곤함이 아니라,

# **졸림·과식·게으름에 계속 끌려 정진이 사라지는 상태**

입니다.

---

## “감각기관을 없애야 생사가 끝난다”

제601~602경을 그렇게 읽지 않습니다.

앞 권 전체에서 반복된 핵심은,

# **감각 조건에서 생기는 욕탐과 결박의 소멸**

입니다.

# 호킨스 박사님 언어로 다시 보기

아래는 『잡아함경』 제22권의 직접 표현이 아니라, 같은 내용을 호킨스 박사님의 개념 체계로 다시 비춰보는 비교 해설입니다.

## 연결되는 지점

제581~582경은 아주 중요한 구분을 줍니다.

# **언어 속의 ‘나’**
와
# **마음이 실체적으로 붙잡는 ‘나’**

는 같은 것이 아닙니다.

호킨스 박사님의 언어로 제한적으로 비교하면,
**일상적 역할과 표현을 사용하면서도 그 내용과 완전히 동일시하지 않는 태도**와 비교할 수 있습니다.

제591경은,

# **말로 옳은 것을 주장하는 것과 실제 삶의 위치성이 일치하는가**

를 묻는 장면으로 비교할 수 있습니다.

제603경의,

# **신뢰·불방일·정진·지혜**

는 의도와 꾸준한 실천이 단순한 개념적 이해보다 중요하다는 점에서 제한적인 비교가 가능합니다.

---

## 중요한 차이

그러나 다음처럼 동일시하지 않습니다.

### 세속가명 = Witness
아닙니다.

### 적멸 = Presence
아닙니다.

### 천상 = 의식수준
아닙니다.

### 지혜 = 호킨스식 knowingness
기계적으로 같은 개념이 아닙니다.

### 무아 = Self의 발견
아닙니다.

특히 제581~582경은,

# **‘나’라는 말을 사용하지만 아만이 없다**

고 말할 뿐,

# **그 뒤에 영원한 참나가 숨어 있다**

고 말하지 않습니다.

---

# 제22권 최종 정리

『잡아함경』 제22권은 천신 이야기로 시작합니다.

한 천신은,

> **“삼십삼천의 난다원에 있어야 진정한 행복이다.”**

라고 말합니다.

부처님의 답은,

# **“모든 행은 무상하고 생겼다가 멸한다. 그 적멸이 안락하다.”**

입니다.

처음부터 천상을 최종 목표에서 내려놓습니다.

그리고 아주 중요한 무아의 언어 문제가 나옵니다.

천신은 묻습니다.

> **“아라한도 ‘내가’라고 말합니까?”**

부처님은,

# **말할 수 있다**

고 답합니다.

하지만 아라한은,

# **아만에서 떠났고**
# **나·내 것에 마음이 붙지 않으며**
# **세상의 명칭을 가명으로 이해해 말합니다.**

따라서 무아는,
일상언어에서 1인칭을 삭제하는 수행이 아닙니다.

# **오온과 경험에 실체적 ‘나’를 붙여 집착하지 않는 것**

이 핵심입니다.

중간의 제590경에서는 재가 수행자가 등장합니다.

그는 밤에 앉아,

# **무명에서 노사까지의 연기를 순관하고**
# **다시 무명멸에서 괴로움의 멸까지 역관합니다.**

재가 수행도 깊은 연기 관찰까지 갈 수 있음을 보여 줍니다.

바로 다음 제591경은 반대 사례입니다.

남 앞에서는 욕망을 비판하면서,
집에 돌아와서는 욕망에 탐닉합니다.

천신은 그 모순을 지적합니다.

# **법을 잘 말하는가보다 삶이 실제로 그 법과 맞는가**

가 중요합니다.

제592경부터 급고독 장자의 이야기가 나옵니다.

그는 처음 ‘부처’라는 이름을 듣는 순간 크게 기뻐합니다.

그러나 그 신뢰는 감정에서 끝나지 않습니다.

부처님의,

# **보시**
# **계**
# **천상**
# **욕망의 맛·위험·벗어남**
# **멀리 떠남**

에 관한 법을 듣고,

# **법을 보고 의심을 건너**
# **불·법·승에 귀의합니다.**

그리고 승가를 위해 정사를 세우겠다고 합니다.

따라서 신뢰는,

# **듣기**
→ **검토**
→ **이해**
→ **귀의**
→ **실천과 보시**

로 깊어집니다.

마지막 제596~603경은 다시 짧은 천신 게송입니다.

그러나 여기서 핵심 수행 요소가 압축됩니다.

# **계**
# **삼매**
# **정념**
# **감각수호**
# **정진**
# **지혜**

입니다.

그리고 제603경은 모든 것을 네 문장으로 끝냅니다.

# **신뢰로 여러 흐름을 건넌다.**
# **불방일로 큰 바다를 건넌다.**
# **정진으로 괴로움을 덜어 낸다.**
# **지혜로 청정해진다.**

제22권 전체를 가장 간단히 말하면,

# **좋은 곳에 가는 것보다 집착을 끝내는 것이 중요하고**
# **말의 형식보다 마음의 집착 여부가 중요하며**
# **믿음만보다 믿음이 불방일·정진·지혜로 자라는 것이 중요하다**

는 권입니다.

---

# 제22권을 한 문장으로

# **『잡아함경』 제22권은 천신들과의 게송 문답을 통해 천상의 즐거움조차 무상한 생멸법이며 적멸이 더 큰 안락임을 밝히고, 아라한이 일상어로 ‘나’를 말해도 아만에 집착하지 않는 세속가명을 설명한 뒤, 재가자의 연기 관찰과 급고독 장자의 귀의·보시 전승을 거쳐 신뢰·불방일·정진·지혜로 욕탐과 생사의 흐름을 건너 청정에 이르는 길을 압축한다.**
