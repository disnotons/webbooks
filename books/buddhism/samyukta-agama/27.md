# 『잡아함경 쉬운 완전읽기』 제27권
## 깨달음의 일곱 요소는 무엇을 먹고 자라는가 — 오개·정사유·선지식·칠각지·자애·호흡·무상관

> **범위:** 『잡아함경』 제27권, 제712경~제747경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』 卷第二十七  
> **수록 경수:** **36경**  
> **읽기 방식:** 제27권의 중심은 거의 전부 **칠각지(七覺分), 곧 깨달음으로 기울게 하는 일곱 수행 요소**다. 제712경은 앞 권의 마지막 질문인 “번뇌와 청정은 원인 없이 생기는가?”를 다시 확인하고, 제713~717경은 **오개와 칠각지의 세부 구조·마음 상태에 따른 조절·먹이와 굶기기·정사유·선지식**을 설명한다. 제718~740경은 **칠각지를 자유롭게 쓰는 숙련·좋은 벗·점진적 발생·수행 결과**를 반복해 확인하고, 제741~747경은 **부정관·죽음의 기억·자애·무색정·호흡·무상관 등 여러 수행을 칠각지와 연결**한다.

---

# 한 문장 핵심

『잡아함경』 제27권은 이렇게 정리할 수 있습니다.

# **마음의 장애인 오개와 깨달음의 일곱 요소는 저절로 커지거나 사라지는 것이 아니라 각각 ‘먹이’가 있으며, 수행자는 마음이 처졌을 때는 법을 살피는 힘·정진·기쁨을 일으키고 마음이 들떴을 때는 가라앉음·삼매·평형을 키워 균형을 맞춘다. 안에서는 바른 사유가, 밖에서는 좋은 벗이 이 과정을 돕고, 사념처·자애·호흡·무상관 같은 여러 수행도 결국 이욕·소멸·놓아버림으로 향하는 칠각지 안에서 익어 간다.**

이번 권의 큰 구조는 다음과 같습니다.

# **오개**
→ 마음을 덮고 지혜를 약하게 함

# **칠각지**
→ 마음을 깨달음 쪽으로 일으킴

그리고 핵심은,

# **무엇을 먹이느냐**
입니다.

# **그릇된 사유**
→ 오개를 먹임

# **바른 사유**
→ 칠각지를 먹임

# **나쁜 벗**
→ 오개 증가

# **좋은 벗**
→ 칠각지 증가

마음 상태에 따라서는,

# **처진 마음**
→ 법의 분별·정진·기쁨

# **들뜬 마음**
→ 가라앉음·삼매·평형

으로 균형을 맞춥니다.

---

# 먼저 알아둘 두 묶음

제27권은 두 목록이 계속 반복됩니다.

## 오개(五蓋) — 마음을 덮는 다섯 장애

1. **탐욕**
2. **성냄**
3. **졸림·무기력**
4. **들뜸·후회**
5. **의심**

입니다.

오개는,

# **마음을 덮고**
# **지혜의 힘을 약하게 하며**
# **열반으로 향하는 것을 방해합니다.**

---

## 칠각지(七覺分) — 깨달음의 일곱 요소

1. **마음챙김**
2. **법의 분별**
3. **정진**
4. **기쁨**
5. **가라앉음·안정**
6. **삼매**
7. **평형**

입니다.

원문의 `猗覺分`은 팔리 전승의 **passaddhi**와 대응하는 요소로,
여기서는 초보자가 이해하기 쉽게 **몸과 마음이 가라앉고 안정되는 요소**라고 풀겠습니다.

칠각지는 단순한 기분 목록이 아닙니다.

# **이욕**
# **무욕**
# **소멸**
# **놓아버림**

을 향해 닦는 깨달음의 수행 요소입니다.

# 제1경군 — 제712~717경
## 번뇌와 깨달음에는 먹이가 있다 — 정사유와 선지식

---

# 제712경 — 지혜와 무지도 원인 없이 생기지 않는다

제712경은 제711경의 내용을 압축해서 반복합니다.

어떤 사문·바라문은,

> **“중생이 지혜가 없고 보지 못하는 것도 원인 없이 생기며, 지혜와 봄도 원인 없이 생긴다.”**

고 주장합니다.

현존 경문은 앞 경의 설명을 이어,

# **그렇지 않다**

는 방향으로 설명합니다.

즉,

# **무지에도 조건이 있고**
# **지혜에도 조건이 있습니다.**

[연결]

제711경의,

# **번뇌에도 원인·조건이 있고**
# **청정에도 원인·조건이 있다**

는 결론을 바로 이어 받는 경입니다.

[주의]

이 경의 핵심은,

# **사람은 원래부터 지혜로운 사람·어리석은 사람으로 고정돼 있다**

는 운명론이 아닙니다.

조건이 달라지면 마음의 방향도 달라질 수 있다는 것이 중요합니다.

---

# 제713경 — 오개는 다섯인데 왜 ‘열 가지’, 칠각지는 일곱인데 왜 ‘열네 가지’인가

여러 비구가 외도 수행자들과 대화합니다.

외도들은 말합니다.

> **“우리도 오개를 끊고 사념처에 머물며 칠각지를 닦으라고 한다. 그렇다면 고타마 사문의 가르침과 무엇이 다른가?”**

비구들이 부처님께 돌아와 이를 알리자,
부처님은 더 세밀한 구분을 제시합니다.

---

## 오개를 열 가지 측면으로 본다

### 탐욕
- 안의 탐욕
- 밖의 탐욕

### 성냄
- 성냄
- 성냄을 일으키는 표상

### 졸림·무기력
- 졸림
- 잠듦

### 들뜸·후회
- 들뜸
- 후회

### 의심
- 선법에 대한 의심
- 불선법에 대한 의심

입니다.

이렇게 **다섯 장애를 두 측면씩 세분**해 열 가지라고 설명합니다.

---

## 칠각지도 열네 측면으로 본다

### 마음챙김
- 안의 법에 대한 마음챙김
- 밖의 법에 대한 마음챙김

### 법의 분별
- 선법을 분별함
- 불선법을 분별함

### 정진
- 불선법을 끊는 정진
- 선법을 키우는 정진

### 기쁨
- 기쁨
- 기쁨이 일어나는 조건

### 가라앉음
- 몸의 가라앉음
- 마음의 가라앉음

### 삼매
- 삼매
- 삼매의 표상

### 평형
- 선법에 대한 놓음
- 불선법에 대한 놓음

입니다.

---

## 제713경의 포인트

똑같이,

# **“오개를 끊는다.”**
# **“칠각지를 닦는다.”**

라고 말하더라도,
실제 수행에서는 **무엇을 어떻게 관찰하고 조절하는지**가 중요하다는 것입니다.

[주의]

이 경의 외도 비판 표현을,
현대의 다른 종교나 수행 전통을 모욕하는 근거로 사용하지 않습니다.

이번 해설에서 가져올 핵심은,

# **이름이 같은 수행법보다 그 내부 구조와 작동 방식을 확인하라**

는 점입니다.

---

# 제714경 — 처진 마음과 들뜬 마음에는 다른 약이 필요하다

제714경은 제27권의 가장 실용적인 경 가운데 하나입니다.

질문은 간단합니다.

# **마음이 가라앉아 처지고 망설일 때 무엇을 닦아야 하는가?**
# **마음이 들떠 흔들릴 때 무엇을 닦아야 하는가?**

---

## 마음이 처졌을 때

마음이 약해지고 처졌을 때,

# **가라앉음**
# **삼매**
# **평형**

을 더 밀어붙이면 적절하지 않을 수 있습니다.

[비유]

작은 불을 살리고 싶은데
그 위에 숯가루나 재를 더 덮으면
더 꺼질 수 있는 것과 같습니다.

이때는,

# **법의 분별**
# **정진**
# **기쁨**

을 닦습니다.

[비유]

작은 불에 마른 장작을 넣어
불길을 다시 살리는 것과 같습니다.

---

## 마음이 들떴을 때

반대로 마음이 흥분하고 산란할 때,

# **법의 분별**
# **정진**
# **기쁨**

을 더 강하게 밀어붙이면
오히려 들뜸이 커질 수 있습니다.

[비유]

이미 활활 타는 불에
마른 장작을 더 넣는 것과 같습니다.

이때는,

# **가라앉음**
# **삼매**
# **평형**

을 닦습니다.

불길을 잦아들게 하는 방향입니다.

---

## 마음챙김은 어느 때나 돕는다

제714경은 마지막에,

# **마음챙김의 깨달음 요소는 모든 경우를 함께 돕는다**

고 합니다.

이것이 중요합니다.

마음챙김은 먼저,

# **“지금 마음이 처졌는가, 들떴는가?”**

를 알아차리게 합니다.

그 뒤 알맞은 요소를 선택합니다.

---

## [주의] 수행은 항상 같은 힘으로 밀어붙이는 것인가

아닙니다.

제714경은 정반대입니다.

# **수행은 상태를 진단하고 균형을 맞추는 일**

입니다.

피곤하고 침체된 사람에게 더 가라앉으라고만 하면 안 되고,
흥분하고 산란한 사람에게 더 자극적인 정진만 요구해서도 안 됩니다.

---

# 제715경 — 오개와 칠각지는 무엇을 ‘먹고’ 자라는가

제715경은 제27권의 중심 경입니다.

[비유]

# **몸이 음식으로 유지되는 것처럼**
# **오개도 먹이가 있어야 자라고**
# **칠각지도 먹이가 있어야 자랍니다.**

번뇌를 단순히,

> **“없애야 한다.”**

라고 명령하는 것보다,

# **“무엇이 이 번뇌를 먹이고 있는가?”**

를 묻는 방식입니다.

---

# 오개의 먹이

## 탐욕의 먹이

매력적인 대상의 표상을 만나,

# **그릇되게 반복해서 생각하는 것**

이 탐욕을 키웁니다.

---

## 성냄의 먹이

막힘·거슬림·분노를 일으키는 표상을 만나,

# **그릇되게 반복해서 생각하는 것**

이 성냄을 키웁니다.

---

## 졸림·무기력의 먹이

경은,

### 마음의 약함
### 즐거워하지 않음
### 하품
### 과식
### 게으름

을 듭니다.

이것들을 그릇되게 다루면
졸림과 무기력이 더 커집니다.

---

## 들뜸·후회의 먹이

### 친척에 대한 생각
### 사람들에 대한 생각
### 천상에 대한 생각
### 과거 오락에 대한 기억

등을 계속 떠올리고 그릇되게 생각하면
산란과 후회가 자랄 수 있다고 합니다.

---

## 의심의 먹이

### 과거
### 미래
### 현재

에 대한 의혹을
그릇되게 반복하면 의심이 자랍니다.

[주의]

# **질문하지 말라는 뜻이 아닙니다.**

제2강의 깔라마 경에서 보았듯
검토와 지혜는 중요합니다.

여기서 문제는,

# **답을 찾는 검토가 아니라 맴돌기만 하며 수행을 마비시키는 의심**

입니다.

---

# 오개를 굶기는 법

제715경은 반대 조건도 줍니다.

# **탐욕**
→ **부정관**

# **성냄**
→ **자애의 마음**

# **졸림**
→ **밝게 깨어 있게 하는 생각**

# **들뜸·후회**
→ **고요하게 멈추는 생각**

# **의심**
→ **연기법을 생각함**

입니다.

---

## [주의] 부정관 = 몸을 미워하기

아닙니다.

부정관은 몸을 혐오해 자기를 공격하는 수행이 아닙니다.

# **감각적 매혹을 과장해 붙잡는 마음을 식히기 위해**
# **몸의 실제 조건과 구성·변화를 균형 있게 보는 수행**

입니다.

---

# 칠각지를 먹이는 법

## 마음챙김
# **사념처를 생각하고 닦는 것**

## 법의 분별
# **선과 불선을 실제로 구분해 살피는 것**

## 정진
# **사정단을 생각하고 닦는 것**

## 기쁨
# **기쁨과 기쁨의 조건을 바르게 살피는 것**

## 가라앉음
# **몸과 마음의 안정·쉼을 살피는 것**

## 삼매
# **사선을 닦는 것**

## 평형
# **끊음·무욕·소멸의 방향을 살피는 것**

입니다.

---

## 제715경의 핵심 질문

번뇌가 강할 때,

# **“나는 왜 이 모양인가?”**

보다 더 실용적인 질문은,

# **“지금 이 번뇌에 무엇을 먹이고 있는가?”**

입니다.

그리고 선한 마음이 약할 때는,

# **“어떤 조건을 주면 칠각지가 자랄까?”**

를 봅니다.

---

# 제716경 — 안의 가장 강한 조건: 그릇된 사유와 바른 사유

부처님은 말합니다.

# **내부 조건 가운데**
# **그릇된 사유만큼 불선법을 키우는 것을 보지 못했다.**

그릇된 사유는,

# **오개를 일으키고 키우며**
# **칠각지가 생기지 못하게 하거나 쇠퇴시킵니다.**

반대로,

# **바른 사유**

는,

# **오개를 막고 끊으며**
# **칠각지를 일으키고 증장합니다.**

[연결]

제704경과 같은 구조입니다.

제27권은 이 원리를 더 구체적인 수행 조절과 연결합니다.

---

# 제717경 — 밖의 가장 강한 조건: 나쁜 벗과 좋은 벗

이번에는 외부 조건입니다.

# **나쁜 벗·나쁜 동료**

는,

# **오개를 키우고**
# **칠각지를 약하게 합니다.**

반대로,

# **좋은 벗·좋은 동료·좋은 동행**

은,

# **오개를 줄이고**
# **칠각지를 일으켜 자라게 합니다.**

---

## 제716~717경을 함께 보면

# **안의 조건**
= **바른 사유**

# **밖의 조건**
= **좋은 벗**

입니다.

초기불교 수행은,

# **“내 마음만 바꾸면 된다.”**

는 개인주의도 아니고,

# **“환경이 전부다.”**

라는 설명도 아닙니다.

# **내가 어떻게 생각하는가**
와
# **누구와 가까이 지내는가**

둘 다 중요합니다.

---

# 제712~717경 전체 요약

# **번뇌와 청정은 무원인이 아니다.**

오개와 칠각지는 모두 조건을 먹고 자랍니다.

# **상태를 진단하고**
# **알맞은 깨달음 요소를 선택하며**
# **바른 사유를 하고**
# **좋은 벗을 가까이하는 것**

이 수행의 핵심 조건입니다.

# 제2경군 — 제718~727경
## 칠각지가 익으면 어떻게 되는가 — 숙련·좋은 벗·전륜왕의 보배·병고 속 정진

---

# 제718경 — 사리불은 칠각지를 원하는 때에 자유롭게 쓴다고 말한다

사리불은 일곱 깨달음 요소를,

# **이미 확실히 얻었고**
# **원할 때 자유롭게 들어갈 수 있다**

고 말합니다.

[비유]

왕의 대신이 여러 옷을 상자에 넣어 두고
아침·낮·저녁 필요에 따라 꺼내 입는 것과 같습니다.

사리불은,

# **마음챙김이 일어날 때 일어남을 알고**
# **사라질 때 사라짐을 알며**
# **나머지 깨달음 요소도 마찬가지로 안다**

고 합니다.

---

## 수행 숙련은 ‘늘 같은 상태’가 아니다

중요한 점은,

# **깨달음 요소가 일어나고 사라지는 것을 안다**

는 것입니다.

숙련은 어떤 상태를 영원히 고정하는 것이 아니라,

# **필요할 때 일으킬 수 있고**
# **생멸을 분명히 아는 능력**

입니다.

---

# 제719~720경 — 칠각지를 제대로 닦고 있는지 어떻게 아는가

우파마와 아티묵타,
그리고 아나율의 문답이 이어집니다.

핵심은,

# **마음이 졸림에 눌리지 않는가**
# **들뜸과 후회가 조복되는가**
# **몸이 안정되는가**
# **마음이 한곳에 머무는가**
# **산란한 생각이 일어나지 않는가**

를 살피는 것입니다.

칠각지 수행의 기준은,

# **목록을 외웠는가**
가 아니라
# **실제 마음의 장애와 불균형이 줄었는가**

입니다.

---

# 제721~722경 — 전륜왕의 일곱 보배와 여래의 일곱 보배

제721경은 전륜왕이 나타날 때,

### 금륜
### 코끼리
### 말
### 보석
### 왕비
### 재정을 맡은 대신
### 군사를 맡은 대신

이라는 일곱 보배가 나타난다는 전승을 말합니다.

그리고,

# **여래가 세상에 나타나면 칠각지라는 일곱 보배가 나타난다**

고 비유합니다.

제722경은 전륜왕의 일곱 보배를 훨씬 길게 묘사한 뒤
다시 칠각지에 연결합니다.

---

## [전승] 전륜왕의 신비한 보배

하늘을 나는 금륜,
하루 만에 세계를 도는 코끼리와 말,
어둠을 밝히는 보석 같은 묘사는
고대 인도의 **전륜왕 이상왕 전승**입니다.

현대 역사적 왕권의 실제 기술로 보지 않습니다.

---

## 칠각지가 진짜 보배인 이유

왕의 보배는,

# **나라를 다스리는 힘**

입니다.

칠각지는,

# **자기 마음의 탐욕·성냄·무지를 넘어 깨달음으로 가는 힘**

입니다.

제25권의 왕권 무상 이야기와 비교하면,
이 비유가 더 선명합니다.

---

# 제723경 — 젊은 수행자가 장로를 가까이하는 이유

젊은 비구가 장로를 공경하고 가까이하면,

# **때때로 깊고 미묘한 법을 듣습니다.**

법을 들으면,

# **몸과 마음이 바르게 되고**
# **마음챙김의 깨달음 요소를 닦고**
# **그 다음 법을 분별하며**
# **마침내 평형까지 칠각지를 충만하게 합니다.**

즉,

# **좋은 벗**
→ **깊은 법을 들음**
→ **몸·마음의 바름**
→ **칠각지**

입니다.

제717경의 선지식이 구체적으로 작동하는 모습입니다.

---

# 제724경 — 계·덕·참괴가 있는 사람을 가까이하라

이번에는 단순히 나이가 많은 사람이 아니라,

# **계를 지키고**
# **덕을 닦고**
# **참과 괴가 있고**
# **진실한 법을 이룬 사람**

을 가까이하라고 합니다.

그런 사람을,

### 보는 것
### 법을 듣는 것
### 기억하는 것
### 따라서 출가하는 것
### 직접 가까이 모시고 배우는 것

에 큰 이익이 있다고 합니다.

---

## [주의] 장로라는 이유만으로 무조건 따르라는 뜻인가

제723~724경을 함께 읽어야 합니다.

제723경은 장로를 말하지만,
제724경은 **계·덕·참괴·진실한 법**을 기준으로 제시합니다.

따라서 단순 연령이나 지위보다,

# **어떤 삶과 수행을 실제로 갖추었는가**

가 중요합니다.

# 제725경 — 불선의 한 덩어리와 선의 한 덩어리

부처님은 아주 간단하게 정리합니다.

# **불선의 집합**
= **오개**

# **선의 충만한 집합**
= **칠각지**

입니다.

제611경과 매우 비슷합니다.

이번 권 전체가 결국,

# **오개에서 칠각지로 마음의 먹이를 바꾸는 과정**

임을 다시 확인합니다.

# 제726경 — 좋은 벗은 범행의 절반이 아니라 ‘전부’

아난다는 혼자 생각합니다.

> **“좋은 벗·좋은 동료는 범행의 절반일 것이다.”**

부처님은 즉시 말합니다.

# **“그렇게 말하지 말라.”**

좋은 벗은,

# **범행의 절반이 아니라 그 전체**

라고 합니다.

왜입니까?

부처님 자신이 좋은 벗이기 때문에
중생들이 그를 의지해,

# **칠각지를 닦고**
# **이욕·무욕·소멸·놓아버림**

으로 향할 수 있기 때문입니다.

---

## [주의] 내 수행은 필요 없고 좋은 스승만 만나면 된다는 뜻인가

아닙니다.

좋은 벗은 대신 수행해 주는 사람이 아니라,

# **바른 길을 보여 주고**
# **그 길을 실제로 걷게 하는 조건**

입니다.

제717경과 연결하면,

# **좋은 벗은 칠각지를 먹이는 강력한 외부 조건**

입니다.

---

# 제727경 — 등에 병이 난 부처님도 칠각지를 듣는다

부처님은 등에 통증이 있어
잠시 눕고 싶다고 합니다.

오른쪽으로 누워,

# **정념·정지**

를 유지한 채
아난다에게 칠각지를 말해 보라고 합니다.

아난다는,

# **마음챙김**
# **법의 분별**
# **정진**
# **기쁨**
# **가라앉음**
# **삼매**
# **평형**

이 모두,

# **이욕**
# **무욕**
# **소멸**
# **놓아버림**

에 의지한다고 설명합니다.

부처님은 특히,

# **“정진을 말했느냐?”**

고 거듭 확인하고,

# **정진을 닦고 많이 닦아 바른 깨달음을 얻었다**

고 강조합니다.

---

## [주의] 칠각지를 들으면 병이 치료된다?

제727경은 부처님이 통증 속에서 칠각지를 듣는 장면을 전합니다.

그러나 현존 경문만으로,

# **칠각지를 듣는 것이 특정 신체 질병의 치료법이라고 보장**

하지 않습니다.

분명하게 확인되는 것은,

# **몸이 아파도 정념·정지를 유지하고**
# **법을 듣고**
# **정진을 놓지 않는 태도**

입니다.

# 제733경 — 사념처에서 칠각지가 차례로 일어난다

제733경은 칠각지가 어떻게 점진적으로 자라는지 보여 줍니다.

몸에서 몸을 관찰하며
마음을 거두고 기억을 놓치지 않을 때,

# **마음챙김의 깨달음 요소**

를 닦습니다.

마음챙김이 충만해지면,

# **법을 선택하고 분별하고 헤아립니다.**

그래서,

# **법의 분별**

이 자랍니다.

이어,

# **정진**
→ **기쁨**
→ **가라앉음**
→ **삼매**
→ **평형**

으로 점차 충만해집니다.

느낌·마음·법을 관찰할 때도 같습니다.

---

## 사념처와 칠각지는 별개의 명상이 아니다

# **사념처가 칠각지의 출발점**

이 될 수 있음을 직접 보여 줍니다.

# **관찰**
→ **분별**
→ **정진**
→ **기쁨**
→ **안정**
→ **삼매**
→ **평형**

이라는 살아 있는 과정입니다.

# 제743경 — 자애·연민·기쁨·평형은 어디까지 깊어질 수 있는가

→ **식입처가 최고**

# **평형을 많이 닦음**
→ **무소유입처가 최고**

라고 연결합니다.

## [주의] 자애 = 어떤 특정 선정 하나?

그렇게 단순한 동일식으로 만들지 않습니다.

제743경은 **네 무량심의 깊은 수행과 특정 삼매 영역을 연결하는 현존 한역의 전승**입니다.

자애의 의미 전체를 어떤 하나의 선정 상태로 환원하지 않습니다.

자애의 기본 뜻은 여전히,

# **원한과 해치려는 마음 없이 모든 존재의 안녕을 바라는 마음**

입니다.

---

# 제744경 — 자애도 칠각지와 결합한다

자애를 많이 닦아 큰 과와 큰 이익을 얻으려면,

# **자애와 함께 칠각지를 닦고**
# **이욕·무욕·소멸·놓아버림**

으로 향합니다.

이 점이 중요합니다.

# **자애는 단지 기분 좋은 감정을 만드는 수행이 아니라**
# **해탈 방향의 칠각지와 결합됩니다.**

---

# 제745경 — 무색의 깊은 삼매도 칠각지와 결합한다

제745경은,

# **공입처**

를 닦고,
그와 함께 칠각지를 닦는다고 말합니다.

이어 현존 경문은 압축해서,

### 식입처
### 무소유입처
### 비상비비상입처

도 같은 방식이라고 합니다.

[주의]

이 깊은 삼매들을,

# **영원한 순수의식**
# **참자아**
# **열반 그 자체**

로 보지 않습니다.

제549경에서도 높은 삼매는
그 발생·위험·소멸과 길을 보아야 한다고 했습니다.

---

# 제746경 — 호흡 마음챙김도 칠각지와 결합한다

# **안나반나념 — 호흡에 대한 마음챙김**

을 많이 닦아 큰 과와 큰 이익을 얻는 방법도,
칠각지와 함께합니다.

즉 호흡은,

# **호흡만 바라보다 끝나는 고립된 기법**

이 아닙니다.

# **마음챙김**
→ **법의 분별**
→ **정진**
→ **기쁨**
→ **가라앉음**
→ **삼매**
→ **평형**

이라는 깨달음의 과정과 연결됩니다.

[주의]

호흡 마음챙김을,

# **단순한 긴장완화·호흡법**

으로만 축소하지 않습니다.

초기경전에서는 해탈의 수행체계 안에 있습니다.

# 제747경 — 무상관을 비롯한 여러 관찰도 칠각지로 이어진다

# **무상하다는 인식**

을 많이 닦고,
칠각지와 결합한다고 합니다.

그리고 현존 본문은 이어 많은 수행을 같은 형식으로 압축합니다.

### 괴로운 것은 자아가 아니라는 관찰
### 음식을 관찰함
### 세상을 집착할 만한 것으로 보지 않는 관찰
### 다함의 관찰
### 끊음의 관찰
### 무욕의 관찰
### 소멸의 관찰
### 위험의 관찰
### 부정관
### 시신이 푸르게 변함
### 곪고 무너짐
### 부풀어 오름
### 해체됨
### 먹혀 남지 않음
### 피
### 분리됨
### 뼈
### 공

등입니다.

## [주의] 시신 관찰 = 죽음과 신체를 혐오하라는 뜻인가

아닙니다.

이 전통의 목적은,

# **몸을 영원하고 안정되고 완전히 내 것인 대상으로 붙잡는 매혹을 약화**

시키는 데 있습니다.

자기 몸을 미워하거나
죽음을 추구하는 것이 아닙니다.

## “세상이 즐겁지 않다”는 우울증 훈련인가

현존 목록의 `一切世間不可樂想`도,

# **세상의 모든 것을 미워하고 무기력해지라**

는 뜻으로 읽지 않습니다.

문맥은,

# **조건 지어진 세상에서 영원한 만족을 얻을 수 있다고 집착하지 않는 관찰**

입니다.

# 제26권과 제27권의 차이

## 제26권
# **오근·오력과 여러 ‘힘’**
을 중심으로,
마지막에 오개와 칠각지의 조건을 열었습니다.

## 제27권
바로 그 주제를 확대해,

# **오개와 칠각지가 정확히 무엇을 먹고 자라는지**
# **마음이 처질 때와 들뜰 때 어떻게 다르게 조절하는지**
# **바른 사유와 선지식이 어떤 역할을 하는지**
# **사념처·자애·호흡·무상관이 칠각지와 어떻게 연결되는지**

를 집중적으로 설명합니다.

제26권이,

# **“수행의 힘은 무엇인가?”**

였다면,

제27권은,

# **“그 힘을 실제 마음 상태에서 어떻게 키우고 조절하는가?”**

에 가깝습니다.

# 제1~27권의 흐름

## 제1권
오온을 왜 나·내 것으로 붙잡을 수 없는가

## 제2권
왜 그래도 계속 오온을 나라고 붙잡는가

## 제3권
자기화는 어떤 조건으로 생기고 사라지는가

## 제4권
그 가르침을 이해한 사람은 세상 속에서 어떻게 살아야 하는가

## 제5권
무아 이해 뒤에도 남는 미세한 ‘나는’과 해탈의 오해

## 제6권
수행의 목적과 괴로움의 흐름을 어떻게 끝내는가

## 제7권
자아견에서 여러 철학적 견해가 어떻게 생기고 수행 전체로 어떻게 끊는가

## 제8권
감각 경험에서 접촉·느낌·갈애·취착이 어떻게 생기는가

## 제9권
감각기관과 대상 자체가 아니라 욕탐이 결박임을 알고 감각문을 지키는 법

## 제10권
무명이 무엇인지 밝히고 연기의 중도와 밝은 앎을 닦는 법

## 제11권
보고 듣되 좋아함과 싫어함에 끌려가지 않는 감각수호

## 제12권
괴로움의 조건 사슬 전체와 유·무 두 극단을 떠난 연기의 중도

## 제13권
육육법으로 감각 경험을 해부하고 ‘사람·나’라는 명칭·업·공·평형까지 연결

## 제14권
연기의 앎을 정견·법주지·혜해탈·44지·77지로 정밀화

## 제15권
네 가지 음식과 사성제를 통해 괴로움의 공급·진단·소멸·길을 통합

## 제16권
주의력·동류 성향·18계와 접촉→느낌→갈애→추구의 조건을 살핌

## 제17권
느낌을 집중 분석해 두 번째 화살과 맛·위험·벗어남을 배움

## 제18권
팔정도·계율·갈등 해결·확신·정명·삼매·정진으로 수행 생활 전체를 점검

## 제19권
업·재생 과보 서사를 읽되 피해자 비난을 피하고 사념처라는 현재 수행으로 돌아옴

## 제20권
사념처를 해탈까지 확장하고 갈등·신분·육념·감각의 흐름·무상심삼매를 살핌

## 제21권
선한 의욕을 사용하고 놓는 구조, 네 청정, 질다 장자의 삼매·신견·욕탐 결박을 살핌

## 제22권
천신·재가자 전승 속에서 무상·세속가명·연기·귀의·불방일을 살핌

## 제23권
아소카왕의 장편 전승을 통해 폭력에서 참회·자비·불법 외호로의 전환을 살핌

## 제24권
사념처를 중심으로 계·감각수호·자타보호·해탈을 통합하고 자등명·법등명으로 마무리

## 제25권
정법 쇠퇴와 아소카의 마지막 보시를 통해 법의 제도와 왕권의 조건성과 무상을 살핌

## 제26권
오근·오력·여러 수행의 힘을 정리하고 번뇌와 청정 모두 조건이 있음을 확인

## 제27권
# **오개와 칠각지를 중심으로 마음이 처질 때와 들뜰 때 서로 다른 깨달음 요소를 조절하고, 번뇌와 깨달음 모두 ‘먹이’를 가진다는 구조를 밝힌 뒤, 내부의 정사유와 외부의 선지식을 핵심 조건으로 삼아 사념처·자애·호흡·무상관 등 여러 수행을 이욕·소멸·놓아버림으로 향하는 칠각지에 통합하는 권**

# 제27권에서 꼭 기억할 열두 문장

## ① 번뇌와 지혜는 원인 없이 생기지 않는다
제712경.

## ② 오개와 칠각지는 단순 목록이 아니라 더 세밀한 작동 구조를 가진다
제713경.

## ③ 마음이 처질 때는 분별·정진·기쁨을, 들떴을 때는 가라앉음·삼매·평형을 닦는다
제714경.

## ④ 마음챙김은 처짐과 들뜸 어느 쪽에서도 수행을 조절하는 데 함께 작동한다
제714경.

## ⑤ 오개도 칠각지도 먹이가 있어야 자란다
제715경.

## ⑥ 탐욕에는 부정관, 성냄에는 자애, 의심에는 연기 관찰 같은 반대 조건을 줄 수 있다
제715경.

## ⑦ 내부의 강력한 조건은 바른 사유이고 외부의 강력한 조건은 좋은 벗이다
제716~717경.

## ⑧ 좋은 벗은 범행의 절반이 아니라 전체라고까지 말한다
제726경.

## ⑨ 몸이 아픈 부처님도 정념·정지를 유지하고 칠각지를 들으며 정진을 강조한다
제727경.

## ⑩ 사념처에서 마음챙김→법분별→정진→기쁨→안정→삼매→평형이 점차 자랄 수 있다
제733·737경.

## ⑪ 자애·호흡·무상관 등 서로 다른 수행도 칠각지와 결합해 이욕·소멸·놓아버림으로 향한다
제741~747경.

## ⑫ 수행은 같은 기술을 무조건 반복하는 것이 아니라, 어떤 조건이 무엇을 키우는지 알고 마음을 조율하는 일이다

# [주의] 제27권에서 생기기 쉬운 대표 오해

## “마음챙김만 계속 강하게 하면 된다”

제714경과 맞지 않습니다.

# **처진 마음과 들뜬 마음은 서로 다른 요소로 조율합니다.**

마음챙김은 상태를 알아차리고 알맞은 요소를 선택하도록 돕습니다.

---

## “번뇌는 의지만 세면 없앨 수 있다”

제715경은 더 구체적으로 봅니다.

# **번뇌에는 먹이가 있습니다.**

무엇을 보고,
어떻게 생각하고,
무엇을 반복하는지가 중요합니다.

---

## “부정관은 몸을 싫어하는 수행이다”

아닙니다.

감각적 매혹을 사실보다 과장해 붙잡는 마음을 줄이는 수행입니다.

신체혐오와 다릅니다.

---

## “죽음의 기억은 죽음을 바라는 수행이다”

아닙니다.

# **죽음이 확실하고 시간은 불확실하다는 사실을 기억해 방일을 줄이는 수행**

입니다.

---

## “좋은 벗이 전부라면 내가 수행할 필요가 없다”

좋은 벗은 수행을 대신하지 않습니다.

# **오개를 줄이고 칠각지를 키울 수 있는 길·법·환경을 제공하는 조건**

입니다.

---

## “칠각지를 들으면 병이 낫는다”

제727경은 부처님의 통증 속 법청취 전승이지만,
특정 질환의 치료 보장은 아닙니다.

의학적 치료와 수행의 기능을 구분합니다.

---

## “칠각지는 일곱 단계를 반드시 기계적으로 차례대로 통과해야 한다”

제733·737경은 점진적 발생을 말하지만,
제714경은 현재 마음 상태에 따라 어떤 요소를 더 강하게 닦을지 조절합니다.

따라서,

# **순서와 균형이라는 두 측면**

을 함께 봐야 합니다.

---

## “자애는 공입처 같은 선정과 동일하다”

제743경은 네 무량심과 특정 깊은 삼매의 최고점을 연결하는 전승입니다.

자애 자체를 특정 삼매 하나로 정의하지 않습니다.

---

## “무색정의 식입처는 영원한 순수의식이다”

아닙니다.

식입처도 조건 지어진 삼매 성취입니다.

열반이나 영원한 Self와 자동 동일시하지 않습니다.

---

## “무상·부정·시신관은 세상을 혐오하고 우울해지는 수행이다”

제747경의 방향은,

# **영원한 만족을 준다고 잘못 붙잡는 매혹에서 벗어남**

입니다.

혐오·절망·자기파괴가 목표가 아닙니다.

## 연결되는 지점

제714경은 마음 상태를 먼저 보고,
그 상태에 맞게 수행 요소를 조절합니다.

호킨스 박사님의 언어로 제한적으로 비교하면,

# **마음에서 일어나는 내용을 곧바로 ‘나’로 동일시하지 않고 관찰한 뒤**
# **그 상태를 강화할 것인지 놓아 줄 것인지 분별하는 과정**

과 일부 비교할 수 있습니다.

제715경의 ‘먹이’ 비유도,

# **주의가 계속 향하는 곳과 반복되는 생각이 특정 마음 상태를 강화한다**

는 점에서 비교할 여지가 있습니다.

제716~717경은,

# **내적 위치와 외적 맥락이 함께 마음의 방향에 영향을 준다**

는 점을 보여 줍니다.

# 제27권 최종 정리

『잡아함경』 제27권은,
수행을 아주 현실적인 질문으로 바꿉니다.

# **“내 마음이 지금 어떤 상태인가?”**

마음이 처져 있고 힘이 없다면,
고요·삼매·평형만 더하는 것이 항상 좋은 것은 아닙니다.

그럴 때는,

# **법을 다시 살피고**
# **정진을 일으키고**
# **선한 기쁨을 살립니다.**

반대로 마음이 너무 들떠 있다면,
정진과 기쁨을 더 자극할 때가 아닐 수 있습니다.

그럴 때는,

# **몸과 마음을 가라앉히고**
# **삼매를 키우고**
# **평형을 닦습니다.**

그리고 마음챙김은
이 모든 상황에서 함께합니다.

왜냐하면 먼저,

# **지금 마음이 어느 쪽으로 기울었는지 알아야 하기 때문입니다.**

제715경은 한 걸음 더 들어갑니다.

오개도 칠각지도,

# **먹이가 있습니다.**

탐욕이 커진다면,
“나는 탐욕스러운 사람”이라고 정체성을 만들기보다,

# **무엇을 반복해서 보고 생각하며 탐욕을 먹이고 있는가**

를 봅니다.

성냄도 마찬가지입니다.

졸림,
들뜸,
의심도 마찬가지입니다.

반대로 칠각지가 약하다면,

# **사념처**
# **선악의 분별**
# **정진**
# **기쁨의 조건**
# **몸과 마음의 안정**
# **삼매**
# **소멸과 놓아버림의 방향**

에 먹이를 줍니다.

제716~717경에서는
조건을 안과 밖으로 나눕니다.

안에서는,

# **바른 사유**

가 중요합니다.

밖에서는,

# **좋은 벗**

이 중요합니다.

아난다는 좋은 벗이 범행의 절반이라고 생각했지만,
부처님은,

# **“절반이 아니라 전부다.”**

라고까지 말합니다.

좋은 벗은 나 대신 깨닫는 사람이 아닙니다.

그러나,

# **무엇을 배우고**
# **어떤 말을 반복해서 듣고**
# **무엇을 정상이라고 여기며**
# **어느 방향으로 마음을 기울이는가**

에 강력한 영향을 줍니다.

제733경에서는
사념처와 칠각지가 이어집니다.

몸·느낌·마음·법을 놓치지 않고 관찰하면,

# **마음챙김**
이 자리 잡고,

그 위에서,

# **법을 분별하고**
# **정진하고**
# **기쁨이 생기고**
# **몸과 마음이 안정되며**
# **삼매가 깊어지고**
# **평형으로 갑니다.**

마지막 제741~747경은
서로 다른 명상들을 한 방향으로 모읍니다.

부정관,
죽음의 기억,
자애,
무색의 깊은 삼매,
호흡 마음챙김,
무상관.

이 모든 것은 이름이 다릅니다.

그러나 경은 반복해서,

# **칠각지와 함께 닦아**
# **이욕**
# **무욕**
# **소멸**
# **놓아버림**

으로 향하라고 합니다.

그래서 제27권의 핵심은,

# **“좋은 명상법 하나를 골라 무조건 반복하라.”**

가 아닙니다.

# **마음의 상태를 보고**
# **번뇌가 무엇을 먹고 있는지 보고**
# **깨달음의 요소가 무엇을 필요로 하는지 보고**
# **좋은 사람과 좋은 법을 가까이하며**
# **필요한 수행 요소를 균형 있게 키워라.**

입니다.

---

# 제27권을 한 문장으로

# **『잡아함경』 제27권은 오개와 칠각지가 모두 먹이를 가진 조건적 과정임을 밝히고, 마음이 처질 때는 법분별·정진·기쁨을, 들뜰 때는 가라앉음·삼매·평형을 닦으며 마음챙김으로 전체를 조절하라고 가르친 뒤, 바른 사유와 좋은 벗을 핵심 조건으로 삼아 사념처에서 칠각지를 점진적으로 키우고 부정관·죽음의 기억·자애·무색정·호흡·무상관 같은 여러 수행을 이욕·소멸·놓아버림의 해탈 방향으로 통합한다.**

- 제723~724경의 장로 친근을 연령·지위에 대한 맹목적 복종으로 설명하지 않고 계·덕·참괴·진실한 법의 기준을 함께 제시
- 제726경의 선지식이 범행 전체라는 표현을 ‘스승이 대신 수행해 준다’는 뜻으로 바꾸지 않음
- 제727경의 부처님 병고와 칠각지 법청취를 특정 질병 치료 보장으로 설명하지 않음
- 제733·737경의 칠각지 점진적 발생과 제714경의 상태별 조절을 함께 설명
- 제734~740경의 아나함 세부 열반 유형은 입문자에게 암기를 강요하지 않음
- 제741경의 부정관과 제747경의 시신관을 혐오·우울·죽음 추구로 설명하지 않음
- 제742경의 죽음의 기억을 자해나 죽음 희구와 구분
- 제743경의 자·비·희·사와 특정 삼매 영역의 대응을 현존 한역의 수행 전승으로 보존하되 각 무량심의 정의 자체와 동일시하지 않음
- 제745경의 공·식·무소유·비상비비상입처를 열반·영원한 순수의식·Self와 동일시하지 않음
- 제746경의 호흡 마음챙김을 단순한 이완 호흡법으로 축소하지 않음
- 제747경의 `一切世間不可樂想`을 세상혐오·무기력으로 설명하지 않고 조건 지어진 세상에 대한 집착적 매혹에서 벗어나는 관찰로 설명
- 평행경 정보는 프로젝트 내부 SuttaCentral 평행전승 검색색인을 보조적으로만 사용
- 평행전승의 문장을 현존 한역의 압축·특이 표현에 자동으로 덧씌우지 않음
