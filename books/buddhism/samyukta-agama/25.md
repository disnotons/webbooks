# 『잡아함경 쉬운 완전읽기』 제25권
## 정법은 어떻게 쇠퇴하고, 왕의 권력은 어떻게 사라지는가 — 말법 전승·계율·승가 분열·아소카의 마지막 보시·무상

> **범위:** 『잡아함경』 제25권, 제640경~제641경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』 卷第二十五  
> **수록 경수:** **2경**  
> **읽기 방식:** 제25권은 두 경뿐이지만 내용은 매우 크고 강렬하다. 제640경은 **부처님 사후 정법의 외호와 미래 쇠퇴·전쟁·승가의 타락·계율의 붕괴·교단 내부 살해를 거쳐 ‘정법이 사라진다’는 종말 전승**을 담고 있다. 제641경은 다시 아소카왕 전승으로 돌아가, 천하를 다스리던 왕이 죽음을 앞두고 재산과 권한을 하나씩 잃다가 **마지막으로 자신이 마음대로 쓸 수 있는 반쪽 암라 열매를 승가에 보시하는 장면**을 중심으로 무상과 보시를 말한다.

---

# 한 문장 핵심

『잡아함경』 제25권은 이렇게 정리할 수 있습니다.

# **정법의 쇠퇴는 단순히 시간이 지나서 자동으로 오는 것이 아니라, 수행자가 계·경전·선정·지혜보다 이익·명예·편안함에 물들고 공동체가 다툼과 폭력으로 무너질 때 가속된다는 종말 전승으로 그려진다. 그리고 천하를 다스리던 아소카왕조차 죽음 앞에서는 모든 권력을 잃고 반쪽 열매만 자기 뜻대로 쓸 수 있게 되며, 그 마지막 보시를 통해 부·왕권·몸이 모두 무상하다는 사실을 보여 준다.**

이번 권의 두 흐름은 서로 멀어 보이지만 한 지점에서 만납니다.

# **정법도 조건에 의존해 유지되고**
# **왕권과 재산도 조건에 의존해 유지됩니다.**

조건이 무너지면,

# **교단도 쇠퇴하고**
# **권력도 사라집니다.**

그래서 제25권의 핵심은,

# **“무엇이 영원히 남는가?”**
보다
# **“지금 어떤 조건을 지키고 무엇을 놓아야 하는가?”**

입니다.

---

# 제640경 — 정법은 어떻게 쇠퇴하는가

제640경은 매우 독특합니다.

앞부분에서 부처님은 미래의,

# **우파굽타**
# **수행처**
# **정법의 외호**

를 예언하고,
후반에서는 천 년 뒤의 법 쇠퇴를 매우 비극적인 서사로 묘사합니다.

이 경은 초기불교의 짧은 교리 문답이라기보다,

# **“불법이 어떻게 흥하고 어떻게 무너지는가”를 후대의 역사적 기억과 종말론적 상상 속에서 설명하는 장편 전승**

에 가깝습니다.

---

## 1. 우파굽타와 미래 수행처 예언

부처님은 아난다에게 말합니다.

미래에 마투라 지역에,

# **굽타라는 상인의 아들 우파굽타**

가 나타나고,
부처님 멸도 백 년 뒤,

# **교수하는 스승 가운데 가장 뛰어난 인물**

이 될 것이라고 합니다.

또 한 산의 수행처가,

# **고요함에 가장 알맞은 곳**

이 될 것이라고 예언합니다.

[전승]

우파굽타 예언은 제23권의 아소카 전승과 이어집니다.

역사적으로 별도 검증해야 할 내용을,
부처님의 직접 생전 기록과 같은 층위로 단정하지 않습니다.

---

# 2. 정법을 누구에게 맡길 것인가

부처님은 생각합니다.

> **“정법을 사람에게만 맡기면 오래가지 못할 수 있고, 천신에게만 맡기면 세상 사람들이 법을 받지 못할 수 있다.”**

그래서,

# **사람과 천신이 함께 정법을 지키도록 맡긴다**

는 전승이 나옵니다.

제석천과 사천왕이 부처님 앞에 오고,
부처님은 자신이 곧 열반에 들 것이라 말하며,

# **정법을 보호하라**

고 부탁합니다.

---

## [주의] 불법이 국가나 신비한 존재의 힘으로만 유지된다는 뜻인가

제640경은 천신·왕의 외호를 실제로 중요하게 말합니다.

그러나 같은 경의 후반에서 법을 무너뜨리는 결정적 장면은,

# **비구들이 계율을 버리고**
# **이익과 명예에 빠지고**
# **싸우고**
# **서로 죽이는 것**

입니다.

즉 외부 보호만으로는 충분하지 않습니다.

# **정법의 내부 조건은 수행자 자신의 계·배움·정진·화합**

입니다.

---

# 3. 천 년 뒤 정법 쇠퇴의 징조라는 전승

부처님은 미래에 정법이 쇠퇴할 때,

### 십선이 무너지고
### 악한 바람이 일고
### 비가 제때 오지 않고
### 기근과 우박이 생기며
### 강물이 줄고
### 꽃과 열매가 잘 맺히지 않으며
### 음식의 맛이 떨어지고
### 보물이 사라지는

등의 재난이 일어난다고 전합니다.

[전승]

이것은 제640경의 **말법·재난 전승**입니다.

현대의 기후재난이나 경제위기를 보고,

> **“불교 정법이 사라져서 생긴 일이다.”**

라고 과학적 원인을 대체하는 설명으로 사용하지 않습니다.

---

# 4. 네 악왕과 불교 박해

경은 네 방향에서 왕들이 나타나,

# **탑과 사원을 파괴하고**
# **비구를 죽이며**
# **불교를 박해한다**

고 전합니다.

혼란을 피해 비구들이 중앙 지역으로 모입니다.

[전승]

왕 이름과 박해 서사는 미래 예언의 형식으로 제시됩니다.

이것을 곧바로 정확한 역사 연대표로 확정하지 않습니다.

---

# 5. 난당왕 — 불교를 다시 후원하는 왕

혼란 속에 코삼비의 왕에게
특별한 왕자가 태어납니다.

그가,

# **난당왕**

입니다.

경의 전승에서는 난당왕이 군대를 이끌어
네 악왕을 이기고 세력을 장악합니다.

그 뒤 아버지 왕이 죽자 크게 슬퍼합니다.

한 삼장 법사가 법을 설해
그의 슬픔을 가라앉힙니다.

왕은 불법에 큰 신뢰를 일으켜,

# **비구들에게 두려움 없이 살 수 있게 하고**
# **12년 동안 승가를 크게 공양하겠다**

고 선언합니다.

---

# 6. 풍부한 공양이 오히려 타락의 조건이 되다

여기서 제640경은 매우 날카로운 전환을 보여 줍니다.

왕의 대대적인 공양 덕분에
비구들은 물질적으로 풍족해집니다.

그런데 많은 비구가,

# **신도의 공양을 먹으면서**
# **경전을 읽고 외우지 않고**
# **사람들에게 법을 가르치지 않고**
# **낮에는 잡담하고**
# **밤에는 잠만 자며**
# **이익과 공양을 탐하고**
# **좋은 옷으로 몸을 꾸미고**
# **출요·고요·깨달음의 즐거움에서 멀어진다**

고 합니다.

경은 이들을 매우 거친 말로 비판합니다.

# **겉모양은 비구지만 사문의 공덕에서 멀어진 사람**
# **법 안의 큰 도둑**

이라고까지 표현합니다.

---

## 제640경의 가장 중요한 경고

# **불교가 박해 때문에만 무너지는 것은 아니다.**

오히려,

# **풍족함**
→ **이익과 명예에 대한 탐착**
→ **경·율 학습의 중단**
→ **선정과 지혜의 쇠퇴**
→ **공동체의 타락**

이라는 **내부 붕괴**가 더 무섭게 그려집니다.

[주의]

# **가난해야 수행이 잘된다**

는 단순한 주장도 아닙니다.

앞 권에서는 보시와 승가 후원을 많이 칭찬했습니다.

문제는,

# **공양을 수행의 조건으로 쓰는가**
아니면
# **공양 그 자체에 빠져 수행을 잊는가**

입니다.

---

# 7. 천신들마저 비구들을 멀리한다는 전승

천신·용·귀신 등은
타락한 비구들을 보고 실망해,

# **그들을 비난하고**
# **멀리하고**
# **더는 친근하게 보호하지 않는다**

고 합니다.

그리고,

# **“정법이 곧 사라질 것이다.”**

라고 슬퍼합니다.

[전승]

천신들의 반응은 경전의 종말 전승입니다.

핵심은,

# **도덕과 수행을 잃은 종교적 외형은 보호받을 가치가 없다는 강한 비판**

입니다.

---

# 8. 재가자들이 승가의 싸움을 말리다

코삼비에는 500명의 우바새가 있습니다.

그들은,

# **비구들이 싸운다는 말을 듣고**
# **공동체에 찾아가 다투지 말라고 충고합니다.**

게송에서는,

# **법의 등불이 아직 남아 있을 때**
# **선한 일을 하라**
# **재산은 견고하지 않으니 견고한 공덕을 얻으라**

고 말합니다.

그리고 정법이 사라질 것이라는 두려움 속에서,
하루 만에 많은 탑을 세웠다고 전합니다.

---

## 재가자가 출가 공동체를 바라보는 장면

제640경에서 중요한 점은,

# **재가자가 단순히 공양만 하는 수동적 존재가 아니라**
# **승가의 다툼과 타락을 걱정하고 충고하는 사람들**

로 등장한다는 것입니다.

---

# 9. 마지막 포살 — ‘계율을 설할 필요가 없다’는 삼장 상좌

정법 쇠퇴의 절정에서
많은 비구가 포살을 위해 모입니다.

상좌인 삼장 법사는,

# **“나조차 계율을 배우지 않았는데, 다른 사람이 무엇을 배우겠는가?”**

라는 식으로 말하며,

# **바라제목차를 설할 필요가 없다고 합니다.**

이 장면은 매우 충격적입니다.

---

## 경전을 많이 알아도 계가 무너지면 충분하지 않다

그는 `삼장`으로 묘사됩니다.

즉 많은 경론을 아는 인물입니다.

그런데,

# **계율을 배우지 않고**
# **계율을 설하는 일을 포기합니다.**

제640경은,

# **지식의 양이 계와 수행을 자동 보장하지 않는다**

는 경고를 아주 강하게 던집니다.

---

# 10. 마지막 아라한 수라타 — “부처님이 제정한 계를 모두 지켰다”

그때 수라타라는 아라한이 나섭니다.

그는,

# **“부처님이 제정한 계율을 내가 모두 배우고 지켰다.”**
# **“사리불과 목건련 같은 큰 비구들이 배운 법을 나도 배웠다.”**

고 말하며,

# **바라제목차를 설하라**

고 요구합니다.

그의 게송은 법의 쇠퇴를 슬퍼합니다.

### 법의 다리가 무너지고
### 법의 물이 흐르지 않고
### 법의 바다가 마르고
### 법의 산이 무너지며
### 계율의 장엄이 사라지고
### 감로의 문이 닫힌다

고 노래합니다.

---

# 11. 마하마야가 내려와 슬퍼한다는 전승

부처님의 어머니 마하마야가 천상에서 내려와,

# **아들이 오랜 수행 끝에 성취한 법이 이제 사라진다**

며 통곡한다고 전합니다.

[전승]

마하마야의 천상 하강은 제640경의 종말 전승입니다.

---

# 12. 공동체 내부 살해 — 정법 쇠퇴의 최종 장면

삼장 상좌의 제자 안가다는
수라타 아라한이 자기 스승을 모욕했다고 생각해 격분합니다.

그는,

# **칼로 수라타 아라한을 죽입니다.**

그러자 귀신이 안가다를 죽입니다.

이어 수라타의 제자는
스승이 살해된 것에 분노해,

# **삼장 법사를 죽입니다.**

이렇게,

# **계율 논쟁**
→ **분노**
→ **살인**
→ **보복 살인**

으로 공동체가 완전히 무너집니다.

---

## [주의] 이것이 제640경의 핵심이다

정법이 사라지는 마지막 원인은,
어떤 철학적 논쟁의 패배가 아닙니다.

# **계율의 무시**
# **분노**
# **스승에 대한 맹목적 편들기**
# **폭력**
# **보복**

입니다.

제496~497경에서 배운,

# **사실**
# **적절한 때**
# **유익함**
# **부드러움**
# **자애**

로 갈등을 다루는 방식의 정반대입니다.

---

# 13. “정법이 사라졌다”는 장면

아라한과 삼장 법사가 살해되자,
천신과 사람들이 통곡하고
대지가 흔들렸다고 전합니다.

이어,

# **탑과 절을 부수고**
# **비구를 해치며**
# **불법이 빠르게 쇠퇴한다**

고 합니다.

부처님은 마지막으로 제석과 사천왕에게,

# **정법을 오래 보호하도록 부지런히 노력하라**

고 당부합니다.

---

# 제640경을 한 문장으로

# **제640경은 불법의 쇠퇴를 단순한 시간의 문제가 아니라, 외부 박해와 함께 수행자 내부의 이익 탐착·경율 학습 중단·계율 무시·다툼·분노·폭력이 겹쳐 생기는 조건적 붕괴로 묘사하는 말법 전승이다.**

---

# [주의] 제640경을 어떻게 읽지 말아야 하는가

## “정법은 정확히 천 년 뒤 역사적으로 완전히 사라졌다”

제640경은 그렇게 **예언하는 전승**입니다.

하지만 이것을 현대 역사 연표와 바로 동일시하지 않습니다.

실제로 다양한 불교 전승은 천 년 뒤에도 이어졌습니다.

이번 해설에서는,

# **원문이 전하는 종말론적 전망**

으로 구분합니다.

---

## “재난이 생기면 불교가 쇠퇴한 증거다”

그렇게 단정하지 않습니다.

가뭄·기근·폭풍 등의 자연현상은
현대에는 자연과학적 원인을 따로 분석해야 합니다.

---

## “많은 공양은 승가를 타락시킨다”

공양 자체가 문제가 아닙니다.

# **공양에 집착해 경·율·선정·지혜를 버리는 것**

이 문제입니다.

---

## “삼장을 많이 아는 사람은 제640경에서 악인으로 나오므로 공부는 필요 없다”

정반대입니다.

제640경은,

# **배움과 계율과 수행이 함께 가야 한다**

는 경고로 읽는 것이 적절합니다.

---

## “계율을 지키기 위해 폭력을 써도 된다”

제640경의 최종 붕괴가 바로,

# **계율 논쟁이 살인과 보복으로 변한 것**

입니다.

계율을 명분으로 한 폭력은 정법을 지키는 것이 아니라
오히려 무너뜨리는 장면으로 나옵니다.

---

# 제641경 — 아소카왕의 마지막 반쪽 암라 열매

제641경 제목은 원문에,

# **「阿育王施半阿摩勒果因緣經」**
# **아소카왕이 반쪽 암라 열매를 보시한 인연경**

이라고 적혀 있습니다.

제23권의 아소카 장편 전승과 이어지지만,
이번에는 왕의 **마지막 시기**가 중심입니다.

---

# 1. 급고독 장자보다 더 크게 보시하고 싶었던 왕

아소카는 불법에 큰 신뢰를 가진 뒤 묻습니다.

> **“여래의 법에서 누가 가장 큰 보시를 했습니까?”**

비구들은,

# **급고독 장자**

라고 답합니다.

그가 막대한 재산을 보시했다는 말을 듣고,
아소카는 생각합니다.

# **“나는 왕인데, 그와 같은 액수만 보시해서 되겠는가? 더 크게 하겠다.”**

---

## 보시 규모의 확대

제641경은 아소카가,

### 8만4천 탑을 세우고
### 각 탑에 많은 재물을 보시하고
### 5년 대회를 열고
### 30만 비구를 공양하고

매우 큰 재산을 사용했다고 전합니다.

[전승]

여기 제시되는 거대한 숫자는 아소카 공덕 전승의 수사적 규모를 보여 줍니다.

현대 회계 기록처럼 정확한 금액으로 환산하지 않습니다.

---

# 2. 죽음이 가까워지자 모든 권한이 줄어든다

아소카가 중병에 걸리고
자신의 죽음이 가까움을 압니다.

그런데 그는 아직,

# **자신이 세운 보시 목표가 완성되지 않았다**

고 생각합니다.

남은 재물을 사원으로 보내려 하자,
태자와 대신들은,

# **국가의 재산이 모두 소진될 것을 걱정해**
# **왕이 더 이상 국고를 마음대로 쓰지 못하게 합니다.**

---

## 왕권은 한순간에 사라진다

처음에는 왕에게 금그릇으로 식사를 줍니다.

왕이 그 금그릇을 사원에 보내자,

# **은그릇으로 바꿉니다.**

그것도 보내자,

# **동그릇으로 바꿉니다.**

다시 보내자,

# **질그릇만 줍니다.**

마침내 왕의 손에는,

# **반쪽 암라 열매**

만 남습니다.

---

# 3. “누가 지금 이 땅의 주인인가?”

아소카는 대신들에게 묻습니다.

> **“지금 누가 이 땅의 주인인가?”**

대신들은 형식적으로,

# **“대왕께서 주인입니다.”**

라고 답합니다.

왕은 그것이 사실이 아님을 압니다.

# **“거짓말로 내 마음을 위로하지 말라.”**

고 합니다.

그리고 말합니다.

# **“나는 왕좌에 있지만 이제 마음대로 할 수 있는 것이 없다.”**
# **“오직 이 반쪽 암라 열매만 내 마음대로 할 수 있다.”**

---

## 제641경의 가장 강렬한 장면

한때 아소카는,

# **염부제를 다스리는 왕**

이었습니다.

그러나 죽음 앞에서는,

# **반쪽 과일**

만 자신의 뜻대로 쓸 수 있습니다.

이 장면이 제641경 전체를 압축합니다.

# **권력은 ‘내 것’인 것처럼 보이지만 조건이 바뀌면 즉시 손에서 빠져나갑니다.**

---

# 4. 왕 스스로 무상을 노래한다

아소카는,

# **부귀는 싫어할 만하고 버릴 만하다**

고 노래합니다.

[주의]

여기의 `厭`도 자기혐오나 세상혐오로 읽지 않습니다.

# **영원한 것으로 매혹되어 붙잡을 수 없다는 사실을 깨닫고 집착이 식는 방향**

입니다.

그는,

[비유]

# **강물이 한 번 흘러가면 돌아오지 않듯**
# **부귀도 지나가면 돌아오지 않는다**

고 말합니다.

또,

# **성한 것은 반드시 쇠하고**
# **쇠함이 결국 온다**

는 부처님의 게송을 인용합니다.

---

# 5. 마지막 재산을 승가에 보시하다

아소카는 시종에게 부탁합니다.

# **반쪽 암라 열매를 계작사(鷄雀寺)의 승가에 보내라.**

그리고 전합니다.

# **“나는 한때 염부제를 다스렸지만 지금은 모든 재물에 자유가 없다.”**
# **“오직 이 반쪽 열매만 내 뜻대로 할 수 있다.”**
# **“이것을 나의 마지막 보시로 받아 달라.”**

---

## 보시의 가치는 크기만으로 결정되는가

제641경의 시작에서는
아소카가 급고독 장자보다 **더 많은 액수**를 보시하려고 합니다.

그런데 결말에서는,

# **반쪽 열매 하나**

가 마지막 보시가 됩니다.

이 대비는 매우 중요합니다.

# **보시의 외형적 크기**
보다
# **지금 내가 실제로 놓을 수 있는 것을 놓는 마음**

이 더 선명하게 드러납니다.

---

# 6. 반쪽 열매를 모든 승가가 나누어 먹는다

상좌는 생각합니다.

> **“이 반쪽 열매를 어떻게 모든 비구가 함께 나눌 수 있을까?”**

그래서,

# **열매를 갈아 석류 국에 넣어**
# **모든 승가가 조금씩 나누어 먹게 합니다.**

[비유적 의미]

왕이 마지막으로 가진 작은 물건이,

# **공동체 전체가 함께 받는 보시**

로 바뀝니다.

---

# 7. 왕은 다시 ‘염부제 전체’를 삼보에 보시한다고 선언한다

아소카는 다시 대신들에게,

> **“누가 염부제의 왕인가?”**

라고 묻습니다.

그들은 여전히 왕이라고 답합니다.

아소카는 몸을 일으켜 사방을 향해 합장하고,

# **염부제 전체를 삼보에 보시한다**

고 선언합니다.

그는 그 공덕으로,

# **제석**
# **범천**
# **인간의 왕**
# **세상의 여러 즐거움**

을 구하지 않는다고 말합니다.

대신,

# **최상의 깨달음**
# **일체지**
# **세상의 좋은 벗과 스승이 되는 것**

을 발원합니다.

---

## [전승·주의] 이것은 보살적 발원처럼 보이는 문장이다

현존 제641경에는 실제로,

# **「疾得成佛道」**
# **「成得一切智」**

같은 표현이 있습니다.

이것은 한역 『잡아함경』 제25권의 **아소카 전승 안에 보존된 표현**입니다.

그러나 이를 근거로,

# **초기 니까야·아함의 모든 수행 목표가 후대 대승 보살도와 완전히 동일하다**

고 만들지 않습니다.

전승의 층위를 구분합니다.

---

# 8. 아소카의 죽음과 후계 왕조

아소카는 자신의 보시 선언을 문서로 남기고,
이를 봉인한 뒤 죽었다고 전합니다.

태자·대신·궁중 사람들과 백성들은
왕의 장례를 치릅니다.

이후 대신들은,

# **“왕이 이미 염부제를 삼보에 보시했으므로 그대로 왕위를 계승할 수 없다.”**

고 주장합니다.

그래서 남은 보시 목표에 해당하는 재물을 사원에 보내고,
그 뒤 후계 왕을 세웠다고 전합니다.

---

# 9. 후대 왕의 불교 박해

제641경 후반은 아소카의 후손과 왕위 계승을 나열한 뒤,
한 왕이 나쁜 대신의 말을 듣고,

# **승가와 불법을 파괴하려 한다**

는 이야기로 이어집니다.

### 군대를 일으키고
### 절과 탑을 부수려 하며
### 비구를 죽이고
### 비구의 머리를 가져오면 상을 주겠다고 합니다.

한 아라한은 신통으로 많은 비구 머리를 만들어
국고를 고갈시켰다고 전합니다.

[전승]

이것은 후대 왕조의 불교 박해를 설명하는 전승입니다.

현대 역사학적 연표로 바로 확정하지 않습니다.

---

# 10. 아라한의 멸진정과 탑을 지키는 신들

왕은 한 아라한을 죽이려 하지만,
그가,

# **멸진정에 들어가**

해칠 수 없었다고 합니다.

이후 탑을 지키는 귀신과 다른 신들이 등장하고,
결국 박해 왕과 군대가 죽는다는 전승으로 이어집니다.

[전승]

신통·귀신·산이 무너져 군대를 죽이는 이야기는
제641경의 종교적 서사입니다.

현대 물리적 역사 사실로 강요하지 않습니다.

---

# 11. 제641경의 결론 — 세상의 부귀는 붙잡을 수 없다

제641경의 마지막 평가는 아소카에게 돌아옵니다.

# **세상의 부귀와 즐거움은 탐낼 만한 영원한 것이 아니다.**

아소카는,

# **세상은 무상하고**
# **몸과 생명은 보장되지 않으며**
# **재물도 환영과 같다**

는 사실을 알아,
부지런히 공덕을 짓고
죽음에 이를 때까지 삼보를 기억했다고 찬탄됩니다.

---

# 제641경을 한 문장으로

# **제641경은 천하의 왕이었던 아소카가 죽음 앞에서 재산과 권력을 하나씩 잃고 마지막에는 반쪽 암라 열매만 자기 뜻대로 보시할 수 있게 되는 모습을 통해, 왕권·부귀·몸의 무상함과 ‘지금 실제로 놓을 수 있는 것을 놓는 보시’의 의미를 극적으로 보여 주는 전승이다.**

---

# 제640경과 제641경을 함께 읽으면

두 경은 주제가 달라 보입니다.

제640경은,

# **정법의 쇠퇴**

제641경은,

# **아소카왕의 죽음**

을 말합니다.

그러나 구조는 같습니다.

---

## 정법도 조건에 의존한다

정법은,

# **계**
# **경·율의 배움**
# **선정**
# **지혜**
# **화합**
# **불방일**

이라는 조건으로 유지됩니다.

그 조건이 무너지면
‘불교’라는 이름과 옷이 남아도
내용이 사라질 수 있습니다.

---

## 왕권도 조건에 의존한다

아소카왕의 권력은,

# **국고**
# **대신**
# **태자**
# **정치적 승인**
# **건강과 생명**

이라는 조건 위에 있습니다.

조건이 바뀌자,

# **천하의 주인**
에서
# **반쪽 열매의 주인**

으로 바뀝니다.

---

# 조건 지어진 것은 영원한 소유가 아니다

그래서 제25권 전체는,

# **법의 제도**
와
# **왕의 권력**

이라는 매우 큰 두 대상을 통해,

# **조건 지어진 것은 유지 조건이 있고**
# **그 조건이 사라지면 변화하고 무너진다**

는 사실을 보여 줍니다.

---

# 제24권과 제25권의 차이

## 제24권
# **사념처**
를 수행의 중심에 놓고,
마지막에는 사리불·목건련의 입멸 앞에서,

# **자기 자신을 섬으로**
# **법을 섬으로**

삼으라고 했습니다.

## 제25권
바로 그 다음에,

# **법의 제도적 전승도 쇠퇴할 수 있고**
# **왕의 권력도 사라질 수 있다**

는 거대한 이야기를 보여 줍니다.

그래서 제24권의,

# **법에 의지하라**

는 말은 단순히 종교 조직의 외형에 의지하라는 뜻이 아님이 더 선명해집니다.

제640경 자체가,

# **비구의 옷과 지위가 남아도 계·정진·지혜가 사라질 수 있다**

고 경고하기 때문입니다.

---

# 제1~25권의 흐름

## 제1권
오온을 왜 나·내 것으로 붙잡을 수 없는가

## 제2권
왜 그래도 계속 오온을 나라고 붙잡는가

## 제3권
자기화는 어떤 조건으로 생기고 사라지는가

## 제4권
그 가르침을 이해한 사람은 세상 속에서 어떻게 살아야 하는가

## 제5권
무아 이해 뒤에도 남는 미세한 ‘나는’과 해탈의 오해

## 제6권
수행의 목적과 괴로움의 흐름을 어떻게 끝내는가

## 제7권
자아견에서 여러 철학적 견해가 어떻게 생기고 수행 전체로 어떻게 끊는가

## 제8권
감각 경험에서 접촉·느낌·갈애·취착이 어떻게 생기는가

## 제9권
감각기관과 대상 자체가 아니라 욕탐이 결박임을 알고 감각문을 지키는 법

## 제10권
무명이 무엇인지 밝히고 연기의 중도와 밝은 앎을 닦는 법

## 제11권
보고 듣되 좋아함과 싫어함에 끌려가지 않는 감각수호

## 제12권
괴로움의 조건 사슬 전체와 유·무 두 극단을 떠난 연기의 중도

## 제13권
육육법으로 감각 경험을 해부하고 ‘사람·나’라는 명칭·업·공·평형까지 연결

## 제14권
연기의 앎을 정견·법주지·혜해탈·44지·77지로 정밀화

## 제15권
네 가지 음식과 사성제를 통해 괴로움의 공급·진단·소멸·길을 통합

## 제16권
주의력·동류 성향·18계와 접촉→느낌→갈애→추구의 조건을 살핌

## 제17권
느낌을 집중 분석해 두 번째 화살과 맛·위험·벗어남을 배움

## 제18권
팔정도·계율·갈등 해결·확신·정명·삼매·정진으로 수행 생활 전체를 점검

## 제19권
업·재생 과보 서사를 읽되 피해자 비난을 피하고 사념처라는 현재 수행으로 돌아옴

## 제20권
사념처를 해탈까지 확장하고 갈등·신분·육념·감각의 흐름·무상심삼매를 살핌

## 제21권
선한 의욕을 사용하고 놓는 구조, 네 청정, 질다 장자의 삼매·신견·욕탐 결박을 살핌

## 제22권
천신·재가자 전승 속에서 무상·세속가명·연기·귀의·불방일을 살핌

## 제23권
아소카왕의 장편 전승을 통해 폭력에서 참회·자비·불법 외호로의 전환을 살핌

## 제24권
사념처를 중심으로 계·감각수호·자타보호·해탈을 통합하고 자등명·법등명으로 마무리

## 제25권
# **정법의 쇠퇴를 외부 박해뿐 아니라 승가 내부의 이익 탐착·계율 무시·다툼·폭력이라는 조건적 붕괴로 묘사하고, 죽음을 앞둔 아소카가 천하의 왕에서 반쪽 암라 열매만 자유롭게 보시할 수 있는 사람으로 변하는 모습을 통해 법의 제도와 세속 권력 모두 조건 지어지고 무상함을 보여 주는 권**

---

# 제25권에서 꼭 기억할 열두 문장

## ① 제640경은 정법 쇠퇴를 미래 예언 형식으로 길게 묘사하는 종말 전승이다

## ② 정법은 외부 박해만으로 무너지지 않고 내부 수행의 붕괴로도 무너진다

## ③ 풍부한 공양 자체보다 그 공양에 물들어 경·율·선정·지혜를 버리는 것이 문제다

## ④ 삼장을 많이 알아도 계율과 수행이 무너지면 정법을 지킬 수 없다

## ⑤ 정법 쇠퇴의 마지막 장면은 계율 논쟁이 분노·살인·보복으로 변하는 모습이다

## ⑥ 계율을 지킨다는 명분으로 폭력을 쓰는 것은 제640경에서 정법 수호가 아니라 정법 붕괴의 모습으로 나온다

## ⑦ 제641경은 급고독 장자보다 더 큰 보시를 하려 한 아소카의 마지막 시기를 다룬다

## ⑧ 죽음이 가까워지자 아소카는 왕좌에 있어도 국고를 마음대로 쓸 수 없게 된다

## ⑨ 천하의 왕에게 마지막으로 자유롭게 남은 재산은 반쪽 암라 열매였다

## ⑩ 보시의 의미는 단순히 액수의 크기가 아니라 지금 실제로 놓을 수 있는 것을 놓는 데서 드러난다

## ⑪ 아소카 자신이 부귀의 쇠퇴와 몸의 무상을 게송으로 노래한다

## ⑫ 정법도 왕권도 유지 조건이 있으며, 조건 지어진 것은 영원한 소유가 아니다

겉으로 비구의 옷을 입고 많은 지원을 받아도,
그 지원이,

# **명예와 이익을 지키는 위치성**

으로 굳어지면 법의 목적에서 멀어질 수 있습니다.

제641경의 아소카는,

# **‘천하의 주인’이라는 위치성이 실제 조건 하나하나가 사라지자 유지되지 못하는 모습**

을 보여 줍니다.

호킨스 박사님의 언어로 제한적으로 비교하면,

# **소유와 역할을 자기 정체성으로 붙잡는 위치성이 조건 변화 앞에서 해체되는 장면**

과 비교할 수 있습니다.

# 제25권 최종 정리

『잡아함경』 제25권은
두 종류의 ‘무너짐’을 보여 줍니다.

첫째는,

# **정법의 무너짐**

입니다.

제640경에서 처음에는
왕과 천신들이 불법을 보호합니다.

박해가 지나간 뒤
난당왕은 다시 승가를 크게 후원합니다.

겉으로 보면 불교는 다시 번성합니다.

그런데 바로 그 풍족함 속에서
수행자들이,

# **경전을 읽지 않고**
# **법을 가르치지 않고**
# **밤낮으로 방일하며**
# **좋은 옷과 공양에 집착하고**
# **계율을 가볍게 여기기 시작합니다.**

결국 마지막 포살에서는
삼장 법사가 계율을 설할 필요가 없다고 하고,
이를 바로잡으려는 마지막 아라한과 충돌이 일어납니다.

논쟁은 분노가 되고,
분노는 살인이 되고,
살인은 보복 살인이 됩니다.

제640경에서 정법이 무너지는 마지막 모습은,

# **다른 종교가 논쟁에서 이기는 장면이 아닙니다.**

# **불교를 지킨다고 하는 사람들이 계와 자비를 잃어 서로 죽이는 장면**

입니다.

이것이 이 경의 가장 강한 경고입니다.

둘째는,

# **왕권의 무너짐**

입니다.

제641경의 아소카는
한때 염부제 전체를 다스렸습니다.

급고독 장자보다 더 큰 보시를 하고 싶어
엄청난 재물을 탑과 승가에 사용합니다.

그러나 죽음이 다가오자,
태자와 대신들은 더 이상 왕에게 국고를 맡기지 않습니다.

금그릇이 은그릇으로,
은그릇이 동그릇으로,
동그릇이 질그릇으로 바뀝니다.

마침내 왕이 마음대로 할 수 있는 것은,

# **반쪽 암라 열매 하나**

뿐입니다.

왕은 대신들에게 묻습니다.

> **“누가 이 땅의 주인인가?”**

대신들은 형식적으로 왕이라고 답합니다.

그러나 아소카는 압니다.

# **이제 왕좌에 앉아 있어도 내 뜻대로 되는 것이 없다.**

그는 마지막 반쪽 열매를
승가에 보냅니다.

한때 거대한 재물을 보시하던 왕의 마지막 보시는
작은 과일 반쪽입니다.

그래서 제641경의 질문은,

# **“얼마나 많이 가졌는가?”**

가 아닙니다.

# **“지금 실제로 내 것이라고 붙잡을 수 있는 것이 무엇인가?”**

입니다.

몸도,
왕위도,
국고도,
명령권도,
가족과 대신의 복종도
조건이 달라지면 사라집니다.

제25권은 이렇게
정법과 왕권이라는 매우 큰 두 가지를 나란히 놓습니다.

# **정법도 이름만으로 유지되지 않습니다.**
# **왕권도 이름만으로 유지되지 않습니다.**

둘 다 조건에 달려 있습니다.

그러므로 중요한 것은,

# **외형을 영원한 것으로 붙잡는 것**
이 아니라,

# **법을 유지하는 조건을 지금 지키고**
# **사라질 것은 사라진다는 사실을 알고**
# **놓을 수 있을 때 놓는 것**

입니다.

---

# 제25권을 한 문장으로

# **『잡아함경』 제25권은 제640경에서 정법의 쇠퇴를 외부 박해와 함께 승가 내부의 이익 탐착·계율 무시·학습과 수행의 쇠퇴·분노와 폭력이라는 조건적 붕괴로 묘사하고, 제641경에서는 천하를 다스리던 아소카왕이 죽음 앞에서 모든 권력을 잃고 반쪽 암라 열매만 마지막으로 보시하는 모습을 통해 정법의 제도와 세속의 왕권·재산 모두 조건 지어지고 무상함을 보여 준다.**

- 제641경의 `厭`을 세상·재산 혐오로 설명하지 않고 무상한 부귀에 대한 매혹과 집착이 식는 방향으로 설명
- 제641경의 `成佛道·一切智` 발원을 현존 한역의 아소카 전승으로 보존하되 후대 대승의 전체 체계를 초기 니까야·아함과 자동 동일시하지 않음
- 후계 왕조·불교 박해·아라한 신통·멸진정·귀신 전승을 원문 요소로 보존하되 독립 역사·과학 사실로 자동 확정하지 않음
- 프로젝트 내부 평행전승 검색색인에서 제640~641경의 직접 대응 항목을 확인하지 못했으므로 임의의 평행경을 만들어 넣지 않음
