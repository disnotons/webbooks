# site

모든 웹북이 공유하는 웹사이트 기능과 디자인을 두는 폴더입니다.

이 폴더가 담당할 기능:

- 전체 목차
- 현재 위치
- 이전/다음 이동
- 검색
- 모바일 대응
- 긴 글 가독성
- 다크 모드 등 읽기 기능

각 Markdown 본문에는 사이트용 HTML·CSS·JavaScript나 수동 이전/다음 링크를 반복해서 넣지 않습니다.

실제 공통 웹북 엔진과 GitHub Pages 발행 워크플로는 첫 웹북을 이 저장소에 넣을 때 함께 구성합니다. 불필요한 전체 재빌드를 피하도록 변경된 책만 처리하는 구조를 우선합니다.
